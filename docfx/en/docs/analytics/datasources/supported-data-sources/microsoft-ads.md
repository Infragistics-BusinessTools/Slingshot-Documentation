# Microsoft Ads

The *Microsoft Ads* data source connector allows you to bring your Microsoft advertising data to Slingshot. Use your *Ad account* data to create dashboards and track campaign performance.

## Prerequisites

Before you use the *Microsoft Ads* data source in Analytics, make sure that:

- You have a <a href="https://ads.microsoft.com/" target="_blank" rel="noopener">Microsoft Ads</a> account.
- You have at least one *Ad account* with data that you can access.

## Adding a New Microsoft Ads Data Source Account

If you already added your Microsoft Ads data source to the *Data Sources* list, skip this part and continue with [Setting Up Your Data](#setting-up-your-data).

To add a *Microsoft Ads* data source to your list, follow these steps:

1. Click **+ Dashboard** under **My Analytics**.
2. Click **+ Data Source**.
3. Select *Microsoft Ads* under **Marketing, Sales, and CRMs** in the **Data Sources** list.
4. Sign in with your Microsoft account and allow *Analytics* to access your advertising data.

    > [!NOTE]
    > You need at least one *Ad account* linked to the Microsoft account you use in *Slingshot*.

5. In the next dialog, select the Microsoft ad account you want to analyze, then click **Select and Continue**.
6. In the final dialog, you can update the account name, add a description, check certification status (for *Enterprise* users), and edit details. Select **Add Data Source** to finish.

Your new Microsoft Ads account connection is added to your recently used data sources.

## Setting Up Your Data

From the *Data Sources* list, select the Microsoft Ads account you want to connect. In the *Data Source details* dialog, review the configuration and select **Select Data**.

## Working in the Visualization Editor

After you add the data source, Slingshot opens the *Visualization Editor*. By default, the *Column* visualization is selected. Choose another chart type from the drop-down menu if needed.

When your visualization is ready, save the dashboard in **My Analytics** ⇒ **My Dashboards**, a workspace, or a project.

For more details about data sources, see [Data Sources](../../datasources/overview.md).
