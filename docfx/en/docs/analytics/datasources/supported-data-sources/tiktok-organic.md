# TikTok Organic

The TikTok Organic data source connector in Slingshot lets you analyze unpaid TikTok performance data in dashboards.

## What Is This?

TikTok Organic is a social media connector for non-paid TikTok metrics. Use it to track content performance, engagement trends, and audience activity in one place.

## Prerequisites

Before you connect TikTok Organic, make sure you can sign in to TikTok and access at least one TikTok account with insights data.

## How to Use It

1. Click **+ Dashboard** in **My Analytics**.
2. Click **+ Data Source**.
3. Select **TikTok Organic** under **Social Media**.
4. Sign in with your TikTok profile when prompted.
5. Select the TikTok account you want to analyze, and then click **Select and Continue**.
6. Review the account details, optionally update the name or description, and then click **Add Data Source**.
7. Select a table to open the **Visualization Editor**.
