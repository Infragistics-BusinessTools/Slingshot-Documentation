# YouTube

The YouTube data source allows you to connect your YouTube channel data to Slingshot. With insightful dashboards, you can track video performance, audience engagement, and channel growth.

## Connecting to YouTube

To add a *YouTube* data source to your list, follow the steps below:

1.	Click/tap on the **+ Dashboard** button in a dashboard list.

2. Choose **Blank Dashboard**.

3.	Click on the **+Data Source** button.

4.	Select **YouTube** from the *Data Sources* list.

5.	You will be prompted to log in with your **Google account**. If you manage multiple YouTube channels, make sure you select the account associated with the channel you want to analyze.

6.	A dialog will open, where you can change the name of the data source, add a description, see if the data source is [certified](../../../certifications.md) (available to *Enterprise* users), and edit the details.

7. Choose the channel data you want to use for your dashboard and click on **Select Data**.

## Setting Up Your Data

After connecting to YouTube, you will need to:

1. Add an account. You will be presented with one or more YouTube channels to choose from. Select the channel that you want to analyze and click/tap on **Select and continue**.

2. Add the **Data Source**. Before adding the data source, you can change the account name, add a description, see if the data source is certified (available to *Enterprise* users), and edit the details.

3. Choose a table.

## Working in the Visualization Editor

Once you have chosen a table, you will be taken to the *Visualization Editor*. Here you can build a dashboard while using the data within your table.

The YouTube data is organized in two categories that you can use to build your visualization:

- *Dimensions* contain qualitative data (video title, publish date, etc.).

- *Measures* consist of numeric data (views, likes, comments, watch time, etc.).

>[!NOTE] By default, you will see the *Column* chart. You can select it in order to choose another chart type.

## The Date Range Data Filter

You can filter your data by selecting a specific date range. Keep in mind that the data filter can't be removed but you can change the default date range (*Last 7 days*).

To change the date range, click on the filter and then click on the arrow in the upper right corner.

## Settings

Depending on the chart type you have chosen, you will be able to make different changes in the settings. You can find more information about the different chart types in the data visualizations section [here](../../data-visualizations/overview.md).

When you are ready with the *Visualization Editor*, you can save the dashboard in *My Analytics* ⇒ *My Dashboards*, a specific workspace or a project.
