# Recurring Tasks

Use recurring tasks to automatically repeat work on a schedule, such as every day, every week, or every month.

## What Is This?

Recurring tasks help you manage work that happens regularly without creating each new task manually.

Depending on your setup, you can repeat a task:

- Daily
- Weekly
- Monthly
- Yearly
- A set number of days after completion

You can also choose when the recurring schedule ends, such as never, after a certain number of times, or on a specific date.

## How to Use It

1. Open the task you want to repeat.
2. In the editor toolbar, click the recurring tasks button.
3. Choose how the task should repeat.
4. Select the frequency, such as daily, weekly, monthly, or yearly.
5. If prompted, choose any additional schedule details, such as specific days or dates.
6. Choose when the schedule should end:
   - **Never**
   - **After** a set number of occurrences
   - **On** a specific date
7. Review the schedule details.
8. Click **Save**.

If a recurring schedule is already applied, open the same menu to review, update, or remove it.

> [!NOTE]
> You must have permission to edit the task to save changes to a recurring schedule. If you can only view the task, you may be able to open the scheduler without being able to save or delete changes.

## Tips and Best Practices

- Use recurring tasks for routine work such as weekly check-ins, monthly reporting, or annual renewals.
- Choose **On Completion** trigger to create the next occurrence only after the current task is marked complete.
- Choose a calendar-based schedule if the task should repeat at a fixed interval regardless of when it is completed.
