# 目標

目標を使うと、自分自身、ワークスペース、または組織全体の明確なターゲットを設定し、達成に向けて順調かどうかをひと目で確認できます。進捗は手動でチェックインして追跡することも、目標をダッシュボード ウィジェットに接続して Slingshot に自動更新させることもできます。関連する目標は Strategy の下にまとめたり、OKR を使って主要な結果を通じて目標を測定したりできます。

## 目標の種類

Slingshot には 4 種類の目標があります。それぞれ役割が異なります。

| 種類 | 用途 |
|---|---|
| **Strategy** | 関連する OKR と SMART Goal を 1 か所にまとめます。Strategy にはタイトルと説明のみがあり、独自のターゲットや進捗はありません。 |
| **SMART Goal** | オーナー、サイクル、ステータスを持つ測定可能な目標です。チェックインまたはライブ データで追跡できます。 |
| **OKR** | 「顧客を感動させる」のような定性的な成果を表す目標です。進捗とステータスは Key Result から計算されます。 |
| **Key Result** | OKR 内の測定可能な目標です。SMART Goal と同じように機能し、必ずその OKR に属します。 |

目標は次のように整理できます。

- **Strategy** には OKR と SMART Goal を含めることができます。
- **OKR** には Key Result のみを含めることができます。
- **SMART Goal** は Strategy の中に置くことも、単独で作成することもできます。

### サイクル

SMART Goal、OKR、Key Result にはすべて **サイクル** があります。これはその目標が対象とする期間です。年 (**Annual**)、四半期 (**Quarterly**)、月 (**Monthly**) から選択できます。サイクルは "2026"、"Q2 2026"、"Feb 2026" のように表示されます。

Key Result は既定で親 OKR のサイクルを使用します。必要に応じて、その OKR のサイクル内に収まるより短い期間へ変更できます。たとえば、Q3 の OKR 配下にある Key Result では、Q3、7 月、8 月、9 月を使用できます。

### ステータス

各目標には次のいずれかのステータスが表示されます: **Not Started**、**On Track**、**At Risk**、**Off Track**、**Completed**、**Not Achieved**。**Completed** と **Not Achieved** は最終結果であり、サイクル終了時に目標を完了処理したときに設定されます。

## 目標の保存場所

目標は 3 つの場所で作成できます。

| 場所 | 表示できるユーザー |
|---|---|
| **Personal** | 自分だけです。_Personal Goals_ として表示されます。 |
| **Organization** | 組織内のすべてのユーザーです。 |
| **Workspace** | そのワークスペースのメンバーです。 |

### 目標を見つける

メイン ナビゲーションの **Goals** を開くと、すべての場所にある目標を 1 か所で確認できます。目標は次の 4 つのタブに整理されています。

- **All**: 表示できるすべての目標です。_Location_ 列に目標の保存場所が表示されます。
- **Organization**: 組織の目標です。このタブは組織に所属している場合にのみ表示されます。
- **Workspaces**: すべてのワークスペースの目標です。**Locations** をクリックまたはタップして、含めるワークスペースを選択します。Slingshot は選択内容を記憶します。
- **Personal**: 個人の目標です。

各組織ページとワークスペース ページには **Goals and Strategies** タブもあります。

目標一覧には既定で _Owner_、_Status_、_Progress_、_Cycle_ が表示されます。一覧は _Status_、_Owner_、_Cycle_ でグループ化でき、サイクルやその他のフィールドでフィルターできます。目標にカーソルを合わせると、説明の簡易プレビューと、チェックインが期限切れかどうかを確認できます。

> [!NOTE]
> Slingshot の検索から目標を見つけることもできます。結果の **Goals** カテゴリを確認してください。

## 目標を作成する方法

### 手順 1: 作成する種類を選択する

任意の目標一覧で **+Create** ボタンをクリックまたはタップし、種類を選択します。

- **Strategy**: 関連する目標や目的を 1 か所にまとめます。
- **SMART Goal**: チェックインまたはライブ ダッシュボード データで測定可能なターゲットを追跡します。
- **OKR**: Key Result で測定する定性的な成果です。

グローバル **+** メニューから **Goal** を選択して目標の作成を開始することもできます。既存の Strategy や OKR の中に目標を追加するには、それを開いて **Create OKR**、**Create SMART Goal**、または **Create Key Result** をクリックまたはタップします。これらのオプションは、オーバーフロー メニューの **Add OKR**、**Add SMART Goal**、**Add Key Result** にもあります。

> [!IMPORTANT]
> **Slingshot ヒント**: Slingshot AI を利用できる場合は、最初に自分の言葉で目標を説明するよう求められます。Slingshot AI がレビュー用の目標案を作成します。自分で入力したい場合は **Or create it manually** をクリックまたはタップしてください。

### 手順 2: 場所を選択する

ダイアログ上部の **Choose Location** を使って、目標を保存する場所を **Personal**、所属する組織、またはワークスペースのいずれかから選択します。選択した場所で目標を作成できる場合、Slingshot は現在開いているページを事前選択します。そうでない場合は、組織、次に Personal の順に選択します。

この選択肢には、自分が目標を作成できる場所だけが表示されます。Key Result は常に親 OKR に属するため、Key Result の作成時にはこの選択肢は表示されません。

### 手順 3: 詳細を入力する

目標に _Title_ と任意の _Description_ を設定し、次を指定します。

- **Owner**: 目標の担当者です。既定では自分がオーナーになり、他のユーザーを追加することもできます。オーナーは目標を編集し、チェックインを追加できます。
- **Cycle**: 目標が対象とする期間です。Slingshot は当日の日付に基づいて候補を提案します。
- **Check-in Frequency**: オーナーが目標を更新する頻度です。**Weekly**、**Bi-Weekly**、**Monthly** から選択します (例: "the first Monday of every month")。
- **Strategy**: 必要に応じて目標を既存の Strategy に配置するか、その場で新しい Strategy を作成します。
- **Impact** (Key Result のみ): その Key Result が OKR にどの程度影響するかを設定します。詳細は [OKR の進捗の計算方法](#how-okr-progress-is-calculated) を参照してください。

OKR にはターゲットやチェックイン頻度はありません。進捗は Key Result から算出されるためです。Strategy に必要なのはタイトルと説明だけです。

### 手順 4: 測定方法を設定する

SMART Goal と Key Result には、進捗の追跡方法を定義する **Measurement** セクションがあります。まず **Tracking Source** を選択します。

| Tracking Source | 使用する場面 |
|---|---|
| **Manual** | 各チェックインで現在の値を手動入力する場合に使用します。 |
| **Dashboard Widget** | 数値がすでに Slingshot ダッシュボードにあり、自動で追跡したい場合に使用します。 |
| **Data Source** | ダッシュボードを使わずに、データから直接指標を作成したい場合に使用します。 |

次に、成功条件を定義します。

- **Success Condition**: **Greater Than or Equal to**、**Less Than or Equal to**、または **Between** (**Min** と **Max** を指定)。
- **Target**: 到達したい数値です。年単位および四半期単位の目標では、期間ごと (例: **per month**) に入力することもでき、その場合 Slingshot が合計を計算します。
- **Baseline**: 開始時点の値です (手動目標のみ)。既定値は 0 です。
- **Format**: 値を数値、パーセンテージ、通貨として表示し、小数点や区切り記号のオプションを設定します。

Dashboard Widget と Data Source の目標では、さらに **Measure As** の設定も選択します。

| オプション | 適したケース |
|---|---|
| **Total** | 各期間の値を合計します。売上、新規登録数、クローズしたチケット数などに適しています。 |
| **Average** | サイクル全体の平均を計算します。コンバージョン率、CSAT、直帰率などの割合に適しています。 |
| **Latest** | 最新の値を使用します。購読者数や従業員数など、累積的に変化する値に適しています。 |

### 手順 5: 目標を作成する

**Create** をクリックまたはタップします。新しい目標が自動的に開きます。

## ライブ データで進捗を追跡する

追跡ソースとして **Dashboard Widget** を選択した場合は、**Select Widget…** をクリックまたはタップしてダッシュボードを参照します。数値を保持しているウィジェットを選択し、次を確認します。

- **Metric**: ウィジェットに複数の値がある場合に追跡する値です。
- **Category**: **Grand Total** または、地域や製品などの単一項目を追跡します。
- **Plan** (任意): 同じウィジェット内の 2 つ目の値で、各期間の計画値を表します。Plan を使用すると、ターゲットはその値から計算され、ステータスはその時点までの計画値に対して評価されます。
- **Prior Year** (任意): 比較用として表示する前年の値です。ターゲットやステータスには影響しません。
- **Filters**: この目標に対してウィジェットのフィルターが適切かどうかを確認します。目標のサイクルが期間を決定するため、日付フィルターは不要です。

折れ線、縦棒、横棒、コンボ チャートに加え、ゲージ、KPI、単一値ウィジェットも使用できます。グリッドとピボットは、1 つの日付行と値がある場合に使用できます。円、ドーナツ、エリア、散布図、ファネル、ツリーマップ、マップの各ウィジェットはまだサポートされていません。

データに別のサイクルが適している場合 (例: 四半期目標に対する月次データ)、Slingshot がサイクルの変更を提案します。

Slingshot はライブ データの目標を毎日更新し、目標を作成または変更した直後にも更新します。目標には **Latest Data From** に最終更新日時が表示されます。更新アイコンをクリックまたはタップすると、すぐに更新できます。更新に失敗した場合は、バナーに問題が表示され、最後に同期された値が引き続き表示されます。詳細を確認するには **View Error Details** をクリックまたはタップしてください。

目標の元になっているダッシュボードを開くには、トレンド チャートの下にある **Original Source** をクリックまたはタップします。

> [!NOTE]
> **Data Source** の目標も同じように機能しますが、指標は自分で作成します。データ ソースとテーブルを選択し、日付フィールド、指標、任意の計画値と前年値、さらに必要なフィルターを選択します。このオプションは、まだすべてのアカウントで利用できるわけではありません。

### ダッシュボードから目標を作成する

ダッシュボード自体から開始することもできます。ダッシュボードまたはダッシュボード ウィジェットのオーバーフロー メニューを開き、_Productivity Boost_ セクションから **Create SMART Goal** を選択します。Slingshot は、そのダッシュボード (ウィジェットから開始した場合はそのウィジェットも) がすでに選択された状態で目標エディターを開きます。このオプションは、ダッシュボードに目標で追跡可能なウィジェットが 1 つ以上ある場合にのみ表示されます。

### 自動ステータス

ライブ データの目標では、Slingshot が自動的にステータスを設定します。**Total** 目標では、サイクルの経過割合に対して現在の進捗を比較します。

| サイクルに対する進捗 | ステータス |
|---|---|
| 到達すべき値の 90% 以上 | **On Track** |
| 70% から 90% の間 | **At Risk** |
| 70% 未満 | **Off Track** |

**Average** と **Latest** の目標では、ターゲットを満たしている場合は **On Track**、ターゲットとの差が約 10% 以内であれば **At Risk**、それ以外は **Off Track** です。計画値がある目標は、その時点までの計画値に対して評価されます。

## 目標にチェックインする

チェックインは、オーナーが進捗を記録し、最新情報を共有する方法です。チェックインを追加できるのは目標のオーナーのみです。

1. 目標を開き、**Check-ins** タブに移動します。
2. **+Check-in** をクリックまたはタップします。
3. 手動目標の場合は、**Date**、**Current Value**、**Status** を入力します。
4. 進捗状況に関するメモと、必要に応じて添付ファイルを追加します。
5. **Save** をクリックまたはタップします。

> [!IMPORTANT]
> **Slingshot ヒント**: _Current Value_ は前回からの増分ではなく、現時点での累計値です。85 から 95 増えた場合は、**180** と入力してください。

次の点に注意してください。

- 1 日に追加できるチェックインは 1 件のみです。同じ日に再度保存すると置き換えられます。
- 日付は未来の日付にしたり、目標のサイクル外に設定したりできません。
- サイクルが始まるまではチェックインを追加できません。
- 目標のステータスは、常に日付が最も新しいチェックインに基づきます。
- ライブ データの目標では、値とステータスはデータから取得されるため、チェックインはメモのみになります。
- オーナーは、チェックインのオーバーフロー メニューから任意のチェックインを編集または削除できます。

目標のチェックイン頻度に基づいてチェックインが期限切れになると、目標にバナーが表示されます。オーナーには通知も送信されます。これは通知設定の **Goals** で変更できます。

## 目標を表示する

任意の目標を開くと、**Overview**、**Check-ins**、**Attachments** の 3 つのタブが表示されます。

**Overview** タブには、目標のステータス、オーナー、サイクル、説明が表示され、その下に進捗情報が続きます。

- **Progress card**: 現在の値、変化量、ターゲットに対する現在位置を示すゲージが表示されます。Total 目標では **Velocity** (期間あたりの平均増加量) と、達成までに必要な残りも表示されます。
- **AI summary**: ライブ データの目標では、Slingshot AI が進捗状況の短い要約を作成します。データが変わると更新されます。
- **Trend chart**: 時系列の進捗、チェックイン マーカー、予測トレンド、ターゲットに到達するための理想的な推移が表示されます。遅れている場合は、ここからターゲット達成に必要なペースを示す **Adjusted Target** 線も表示されます。

表示はサイクル全体 (**Yearly**、**Quarterly**、**Monthly**) または期間単位 (**By Month**、**By Week**、**By Day**) に切り替えられます。期間単位の表示はライブ データの目標で利用できます。

<a id="how-okr-progress-is-calculated"></a>
### OKR の進捗の計算方法

OKR の進捗は、各 Key Result の **Impact** で重み付けした Key Result の進捗の平均です。

| Impact | 効果 |
|---|---|
| **High** | 目標全体の進捗とステータスにより大きく影響します。 |
| **Normal** | 他の Key Result と同じ重みで扱われます。既定値です。 |
| **None** | その Key Result 自体は追跡されますが、目標全体の進捗やステータスには影響しません。 |

**High** の Impact を持つ Key Result が **Off Track** の場合、その OKR は最大でも **At Risk** として表示されます。影響対象となる Key Result がすべて完了処理されると、OKR も終了します。すべてが完了していれば **Completed**、そうでなければ **Not Achieved** になります。OKR の表示には、AI の要約と Key Result の一覧も含まれます。

## 目標を完了する

目標のサイクルが終了すると、Slingshot は目標の完了処理を求めます。

- **Manual** 目標: 最終チェックインを追加し、**Completed** または **Not Achieved** を選択します。後から結果を変更する場合は、別の最終チェックインを追加します。
- **Live-data** 目標: 最終データが届くと Slingshot が自動的に完了処理します (またはサイクル終了から 30 日後)。ターゲットに到達していれば **Completed**、そうでなければ **Not Achieved** になります。

サイクルが終了すると目標の設定はロックされ、**Edit** は利用できなくなります。完了のためのチェックインは引き続き追加できます。同じ目標を次のサイクルでも使いたい場合は、**Create a Copy and Edit** を使用します。

## 目標を管理する

追加の操作は、目標のオーバーフロー メニューから実行できます。

| アクション | 内容 |
|---|---|
| **Edit** | 目標の詳細を変更します。サイクル終了後は利用できません。 |
| **Move to...** | Strategy、SMART Goal、OKR を別の場所へ移動します。内部の項目も一緒に移動します。 |
| **Convert to SMART Goal** | Key Result を独立した SMART Goal に変換します。ターゲット、チェックイン、履歴は保持されます。この操作は元に戻せません。 |
| **Create a Copy and Edit** | 同じ設定で新しい SMART Goal または Key Result を開始します。チェックインと履歴はコピーされず、ステータスは **Not Started** から始まります。 |
| **Add to Overview** | 目標をウィジェットとして概要に追加します。 |
| **Delete** | 目標を完全に削除します。 |

ドラッグ アンド ドロップで目標の並び順を変更したり、Strategy の内外へ移動したりすることもできます。

## 概要上の目標

最も重要な目標を概要に追加して、チームの目に入りやすくできます。目標用ウィジェットは 2 種類あり、ウィジェット ライブラリの _Dashboards and Analytics_ にあります。

- **Goal**: 単一の目標の進捗を追跡します。表示領域に余裕があれば、トレンドや Key Result も表示されます。
- **Goals**: 複数の目標、目的、Key Result をピン留めし、進捗をひと目で確認できます。

目標のオーバーフロー メニューから **Add to Overview** を選ぶこともできます。概要にウィジェットを追加できるのは概要のオーナーのみです。

## Slingshot AI と目標

Slingshot AI は、チャットで目標を扱う際にも役立ちます。目標を検索したり、新しい目標を作成したり、既存の目標を更新したりするよう依頼できます。Slingshot AI が目標を提案すると、まずレビュー用のカードが表示されます。承認、編集、スキップを選択できます。複数の目標が一度に提案された場合は、1 件ずつ確認できます。

## 権限

| アクション | 実行できるユーザー |
|---|---|
| 目標を表示する | 目標の保存場所を閲覧できるすべてのユーザー。 |
| 目標を作成する | その保存場所に対して編集権限を持つすべてのユーザー。個人目標は常に自分が作成できます。 |
| 目標を編集、移動、変換する | オーナーを含む、その目標に対する編集権限を持つユーザー。 |
| チェックインを追加、編集、削除する | 目標のオーナーのみ。 |
| 目標を削除する | その目標に対する削除権限を持つユーザー。 |

> [!NOTE]
> 誰かをオーナーとして追加すると、そのユーザーには目標を編集する権限が付与されます。

## 優れた目標を設定するためのヒント

- **重要なものを測定する**: 目標ごとに 1 つの明確な数値を設定し、成果が定性的な場合は OKR を使用します。
- **可能な限りライブ データを接続する**: ダッシュボード連携の目標は自動更新され、ステータスも自動設定されるため、チェックインにかかる時間を減らせます。
- **Total、Average、Latest を目的に応じて使い分ける**: 売上は積み上がりますが、コンバージョン率や従業員数はそうではありません。
- **現実的なチェックイン頻度を設定する**: 四半期目標には毎週、年次目標には毎月が適しています。
- **Key Result で Impact を活用する**: 特に重要な結果には **High** を設定し、本当に重視すべき内容が OKR に反映されるようにします。
