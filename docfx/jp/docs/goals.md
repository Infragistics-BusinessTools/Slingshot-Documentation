# 目標

Goals を使うと、自分、ワークスペース、または組織全体の明確な目標を設定し、達成に向けて順調かどうかを一目で確認できます。進捗は手動でチェックインするか、目標をダッシュボード ウィジェットに接続して Slingshot が自動更新できます。関連する目標を Strategy にまとめたり、OKR を使って Key Result で目的を測定したりできます。

## 目標の種類

Slingshot には 4 種類の目標があります。それぞれ役割が異なります。

| 種類 | 用途 |
|---|---|
| **Strategy** | 関連する OKR と SMART Goal を 1 か所にまとめます。Strategy はタイトルと説明のみを持ち、独自のターゲットや進捗はありません。 |
| **SMART Goal** | 担当者、サイクル、ステータスを持つ測定可能な目標です。チェックインまたはライブ データで追跡します。 |
| **OKR** | 「顧客を感動させる」のような定性的な成果である Objective。進捗とステータスは Key Result から計算されます。 |
| **Key Result** | OKR 内の測定可能な目標。SMART Goal と同様に機能し、必ずその OKR に属します。 |

目標は次のように整理できます。

- **Strategy** には OKR と SMART Goal を含められます。
- **OKR** には Key Result のみを含められます。
- **SMART Goal** は Strategy 内にも単独でも配置できます。

### サイクル

各 SMART Goal、OKR、Key Result には対象期間である **Cycle** があります。年 (**Annual**)、四半期 (**Quarterly**)、月 (**Monthly**) を選べます。表示例は「2026」「Q2 2026」「Feb 2026」です。

Key Result は既定で親 OKR のサイクルを使います。OKR のサイクル内に収まる、より短い期間に変更できます。たとえば、Q3 の OKR 配下の Key Result は Q3、July、August、September を選択できます。

### ステータス

各目標には **Not Started**、**On Track**、**At Risk**、**Off Track**、**Completed**、**Not Achieved** のいずれかが表示されます。**Completed** と **Not Achieved** は最終結果で、サイクル終了時のクローズ時に設定されます。

## 目標の配置先

目標は次の 3 か所に作成できます。

| 場所 | 閲覧できる人 |
|---|---|
| **Personal** | 自分のみ。_Personal Goals_ として表示されます。 |
| **Organization** | 組織内の全員。 |
| **Workspace** | そのワークスペースのメンバー。 |

### 目標を見つける

メイン ナビゲーションの **Goals** を開くと、すべての場所の目標を 1 か所で確認できます。目標は次の 4 タブに整理されています。

- **All**: 表示可能なすべての目標。_Location_ 列に配置先が表示されます。
- **Organization**: 組織の目標。組織に所属している場合のみ表示されます。
- **Workspaces**: すべてのワークスペースの目標。**Locations** をクリック/タップして対象ワークスペースを選択します。選択内容は記憶されます。
- **Personal**: 自分の個人目標。

各組織ページとワークスペース ページには **Goals and Strategies** タブもあります。

目標リストには既定で _Owner_、_Status_、_Progress_、_Cycle_ が表示されます。_Status_、_Owner_、_Cycle_ でグループ化でき、サイクルやその他の項目でフィルターできます。目標にホバーすると、説明のクイック プレビューとチェックイン期限超過の有無を確認できます。

> [!NOTE]
> Slingshot の検索でも目標を見つけられます。結果の **Goals** カテゴリを確認してください。

## 目標を作成する方法

### 手順 1: 作成する種類を選ぶ

任意の目標リストで **+Create** ボタンをクリック/タップし、種類を選びます。

- **Strategy**: 関連する目標と目的を 1 か所にまとめます。
- **SMART Goal**: 測定可能な目標をチェックインまたはライブ ダッシュボード データで追跡します。
- **OKR**: Key Result で測定する定性的な成果です。

グローバル **+** メニューから **Goal** を選んで開始することもできます。既存の Strategy または OKR 内に目標を追加するには、それを開いて **Create OKR**、**Create SMART Goal**、**Create Key Result** をクリック/タップします。これらはオーバーフロー メニュー内の **Add OKR**、**Add SMART Goal**、**Add Key Result** からも実行できます。

> [!IMPORTANT]
> **Slingshot Tip**: Slingshot AI が利用可能な場合、最初に自分の言葉で目標を説明します。Slingshot AI が下書きを作成するので、内容を確認してください。自分で入力したい場合は **Or create it manually** をクリック/タップします。

### 手順 2: 配置先を選ぶ

ダイアログ上部の **Choose Location** で、目標の配置先を **Personal**、組織、またはワークスペースから選択します。作成可能な場所でページを開いている場合はその場所が事前選択され、それ以外では組織、次に Personal が選択されます。

ピッカーには、目標を作成する権限がある場所のみ表示されます。Key Result は常にその OKR 内に作成されるため、Key Result 作成時にはピッカーは表示されません。

### 手順 3: 詳細を入力する

_Title_ と任意の _Description_ を入力し、次を設定します。

- **Owner**: 目標の責任者。既定では自分が所有者で、ほかのユーザーも追加できます。所有者は目標編集とチェックイン追加ができます。
- **Cycle**: 目標の対象期間。Slingshot は今日の日付をもとに候補を提示します。
- **Check-in Frequency**: 所有者が目標を更新する頻度。**Weekly**、**Bi-Weekly**、**Monthly**（例: 「毎月第 1 月曜日」）を選択します。
- **Strategy**: 任意で既存 Strategy 内に配置するか、その場で新規作成します。
- **Impact** (Key Results only): この Key Result が OKR に与える重み。詳細は [How OKR Progress Is Calculated](#how-okr-progress-is-calculated) を参照してください。

OKR は進捗を Key Result から算出するため、ターゲットやチェックイン頻度は持ちません。Strategy に必要なのはタイトルと説明のみです。

### 手順 4: 測定方法を設定する

SMART Goal と Key Result には、進捗追跡方法を定義する **Measurement** セクションがあります。最初に **Tracking Source** を選択します。

| Tracking Source | 使用する場面 |
|---|---|
| **Manual** | 各チェックイン時に現在値を手入力する場合。 |
| **Dashboard Widget** | 数値がすでに Slingshot ダッシュボードにあり、自動追跡したい場合。 |
| **Data Source** | ダッシュボードを介さず、データから直接指標を作成したい場合。 |

次に、成功条件を定義します。

- **Success Condition**: **Greater Than or Equal to**、**Less Than or Equal to**、または **Between**（**Min** と **Max** を指定）。
- **Target**: 目標値。年次/四半期目標では期間ごと（例: **per month**）に入力でき、Slingshot が合計を算出します。
- **Baseline**: 開始値（手動目標）。既定は 0。
- **Format**: 値を数値、パーセント、通貨で表示し、小数や区切りの設定を行います。

Dashboard Widget と Data Source の目標では、**Measure As** も選択します。

| オプション | 適した指標 |
|---|---|
| **Total** | 各期間を合算します。売上、新規登録数、クローズしたチケット向け。 |
| **Average** | サイクル全体の平均を使います。コンバージョン率、CSAT、直帰率向け。 |
| **Latest** | 最新値を使います。登録者数や従業員数のような実績総数向け。 |

### 手順 5: 目標を作成する

**Create** をクリック/タップします。新しい目標が自動的に開きます。

## ライブ データで進捗を追跡する

Tracking Source に **Dashboard Widget** を選んだ場合は、**Select Widget…** をクリック/タップしてダッシュボードを選択します。数値を持つウィジェットを選んだあと、次を確認します。

- **Metric**: ウィジェットに複数値がある場合、追跡する値を選択します。
- **Category**: **Grand Total** を追跡するか、地域や製品など個別項目を追跡するかを選びます。
- **Plan**（任意）: 同じウィジェット内の、各期間の計画値。Plan を使うとターゲットがそこから計算され、ステータスはその時点までの計画に対して評価されます。
- **Prior Year**（任意）: 比較用に昨年値をチャート表示します。ターゲットやステータスには影響しません。
- **Filters**: この目標に対してウィジェットのフィルターが適切か確認します。目標のサイクルが期間を定義するため、日付フィルターは不要です。

折れ線、縦棒、横棒、コンボ チャートに加えて、ゲージ、KPI、単一値ウィジェットも対応しています。グリッドとピボットは、日付行が 1 行で値がある場合に対応します。円、ドーナツ、エリア、散布図、ファネル、ツリーマップ、マップは現在未対応です。

データに別サイクルが適している場合（例: 四半期目標に対して月次データ）、Slingshot はサイクル変更を提案します。

Slingshot はライブ データ目標を毎日更新し、作成・変更時にも即時更新します。目標には **Latest Data From** で最終更新時刻が表示されます。今すぐ更新するには更新アイコンをクリック/タップしてください。更新に失敗した場合はバナーに問題が表示され、直前に同期済みの値を保持します。詳細は **View Error Details** をクリック/タップして確認できます。

目標の元ダッシュボードを開くには、トレンド チャート下の **Original Source** をクリック/タップします。

> [!NOTE]
> **Data Source** 目標も同様の流れですが、指標を自分で構築します。データ ソースとテーブルを選び、日付フィールド、指標、任意の Plan と Prior Year、必要なフィルターを設定します。このオプションは一部アカウントでまだ利用できない場合があります。

### ダッシュボードから目標を作成する

ダッシュボード側から開始することもできます。ダッシュボードまたはダッシュボード ウィジェットのオーバーフロー メニューを開き、_Productivity Boost_ セクションの **Create SMART Goal** を選択します。Slingshot は該当ダッシュボード（ウィジェット起点ならウィジェットも）を事前選択した状態で目標エディターを開きます。このオプションは、目標で追跡可能なウィジェットが 1 つ以上ある場合にのみ表示されます。

### 自動ステータス

ライブ データ目標では、Slingshot が自動でステータスを設定します。**Total** 目標では、進捗をサイクル経過率と比較します。

| サイクルに対する進捗 | ステータス |
|---|---|
| 期待値の 90% 以上 | **On Track** |
| 70% 以上 90% 未満 | **At Risk** |
| 70% 未満 | **Off Track** |

**Average** と **Latest** の目標は、ターゲット達成で **On Track**、約 10% 以内なら **At Risk**、それ以外は **Off Track** です。Plan を使用している場合は、その時点までの Plan に対して評価されます。

## 目標をチェックインする

チェックインは、所有者が進捗を記録し、更新内容を共有する方法です。チェックインを追加できるのは目標の所有者のみです。

1. 目標を開き、**Check-ins** タブに移動します。
2. **+Check-in** をクリック/タップします。
3. 手動目標の場合は **Date**、**Current Value**、**Status** を入力します。
4. 状況メモと、必要に応じて添付ファイルを追加します。
5. **Save** をクリック/タップします。

> [!IMPORTANT]
> **Slingshot Tip**: _Current Value_ は前回からの増分ではなく累計値です。前回が 85 で今回 95 増えた場合、入力値は **180** です。

次の点に注意してください。

- 1 日あたり 1 回までチェックインを追加できます。同日に再保存すると置き換えられます。
- 日付は未来日や目標サイクル外には設定できません。
- サイクル開始前はチェックインを追加できません。
- 目標ステータスは常に日付上もっとも新しいチェックインから決まります。
- ライブ データ目標では、値とステータスはデータから取得されるため、チェックインはメモとして扱われます。
- 所有者は、各チェックインのオーバーフロー メニューから編集や削除ができます。

チェックイン頻度に基づいて期限超過になると、目標にバナーが表示され、所有者にも通知されます。この通知は通知設定の **Goals** で変更できます。

## 目標を表示する

目標を開くと、**Overview**、**Check-ins**、**Attachments** の 3 タブがあります。

**Overview** タブには、目標のステータス、所有者、サイクル、説明が表示され、その後に進捗情報が続きます。

- **Progress card**: 現在値、変化量、ターゲットに対する位置を示すゲージを表示します。Total 目標では **Velocity**（期間あたり平均増加量）と必要な残り量も表示されます。
- **AI summary**: ライブ データ目標では、Slingshot AI が状況の短い要約を作成します。データ更新時に要約も更新されます。
- **Trend chart**: 時系列の進捗、チェックイン マーカー、予測トレンド、理想的な目標到達ラインを表示します。遅れている場合は、ここから目標達成に必要なペースを示す **Adjusted Target** ラインが表示されます。

表示は、サイクル全体（**Yearly**、**Quarterly**、**Monthly**）または期間単位（**By Month**、**By Week**、**By Day**）に切り替えられます。期間単位表示はライブ データ目標で利用できます。

### How OKR Progress Is Calculated

OKR の進捗は、各 Key Result の **Impact** を重みとして適用した、Key Result 進捗の加重平均です。

| Impact | 効果 |
|---|---|
| **High** | 目的の進捗とステータスに、より大きく影響します。 |
| **Normal** | 他の Key Result と同等に扱われます（既定）。 |
| **None** | 単独で追跡され、目的の進捗とステータスに影響しません。 |

**High** の Key Result が **Off Track** の場合、OKR は最大でも **At Risk** までしか上がりません。OKR でカウント対象の Key Result がすべてクローズされると、OKR もクローズされます。すべてが完了なら **Completed**、そうでなければ **Not Achieved** です。OKR ビューには AI summary と Key Result 一覧も表示されます。

## 目標をクローズする

目標サイクルが終了すると、Slingshot からクローズが求められます。

- **手動目標**: 最終チェックインを追加し、**Completed** または **Not Achieved** を選択します。後で結果を変更したい場合は、別の最終チェックインを追加します。
- **ライブ データ目標**: 最終データ到着時（またはサイクル終了 30 日後）に Slingshot が自動でクローズします。ターゲット達成時は **Completed**、未達時は **Not Achieved** です。

サイクル終了後は目標設定がロックされ、**Edit** は利用できません。クローズ用チェックインの追加は可能です。同じ目標を次サイクルで再利用するには **Create a Copy and Edit** を使います。

## 目標を管理する

目標のオーバーフロー メニューから追加アクションを実行できます。

| アクション | 内容 |
|---|---|
| **Edit** | 目標詳細を変更します。サイクル終了後は利用不可です。 |
| **Move to...** | Strategy、SMART Goal、OKR を別の場所へ移動します。内包する項目も一緒に移動します。 |
| **Convert to SMART Goal** | Key Result を独立した SMART Goal に変換します。ターゲット、チェックイン、履歴は保持されます。元に戻せません。 |
| **Create a Copy and Edit** | 同じ設定で新しい SMART Goal または Key Result を開始します。チェックインと履歴はコピーされず、ステータスは **Not Started** で開始します。 |
| **Add to Overview** | 目標を概要にウィジェットとして追加します。 |
| **Delete** | 目標を完全に削除します。 |

ドラッグ アンド ドロップで目標の並び替えや、Strategy への出し入れもできます。

## Home と概要で目標を表示する

重要な目標を自分とチームの前面に配置しましょう。ウィジェット ライブラリの _Dashboards and Analytics_ には 2 種類の目標ウィジェットがあります。

- **Goal**: 1 つの目標進捗を追跡し、スペースがあればトレンドや Key Result も表示します。
- **Goals**: 複数の目標、Objective、Key Result を進捗とともに一覧表示します。

Home 画面には **My Goals** ウィジェットもあります。既定では未クローズ目標（**Completed** と **Not Achieved** 以外）をすべて表示します。

目標のオーバーフロー メニューから **Add to Overview** を選ぶこともできます。概要へのウィジェット追加は概要の所有者のみ可能です。

### Goals ウィジェットをカスタマイズする

Home と概要の Goals ウィジェットでは、表示する目標と表示方法を選べます。ウィジェット メニューから **Edit** を選び、次を設定します。

| 設定 | オプション |
|---|---|
| **Visualization** | **List** または **Cards**。Cards は進捗バー付きで各目標を表示します。 |
| **Goals Source** | **Filter**: 設定したフィルター（ステータス、担当者など）に一致する目標を表示。**Hand-Picked**: **Pick Goals** で個別に選択。 |
| **Group By** | **None**、**Cycle**、**Owner**、**Status**。ソースが **Filter** の場合に利用可能。 |
| **Sort** | 任意の項目で目標を並び替えます。 |
| **Fields** | リストに表示する列を選択します。**List** で利用可能。 |

各目標には進捗、ステータス（**Not Started**、**On Track**、**At Risk**、**Off Track**、**Completed**、**Not Achieved**）、担当者、サイクル残り時間が表示されます。

手動選択時はピッカーが **All** で開くため、目標名で検索し、その後に個人目標とワークスペースをたどって選択できます。

ソースが **Filter** の場合、目標の取得元はウィジェットの配置先に依存します。ワークスペース概要ではそのワークスペースの目標、Home では自分が表示可能なすべての目標が表示されます。

> [!NOTE]
> この更新より前に概要へ追加された Goals ウィジェットは、ピン留め済み目標を保持します。

## Slingshot AI と目標

チャット内で Slingshot AI を使って目標作業を行えます。目標の検索、新規作成、既存更新を依頼できます。Slingshot AI が目標を提案すると、まず確認用カードが表示されます。承認、編集、スキップを選べます。複数提案がある場合は 1 件ずつ確認できます。

## 権限

| 操作 | 実行できる人 |
|---|---|
| 目標を表示する | 目標の配置先を閲覧できるユーザー。 |
| 目標を作成する | 配置先で編集権限を持つユーザー。Personal 目標は常に自分で作成可能。 |
| 目標を編集/移動/変換する | 所有者を含む、目標の編集権限を持つユーザー。 |
| チェックインを追加/編集/削除する | 目標の所有者のみ。 |
| 目標を削除する | 目標に対して削除権限を持つユーザー。 |

> [!NOTE]
> 所有者に追加すると、そのユーザーには目標編集権限も付与されます。

## 良い目標を設定するためのヒント

- **重要な指標を測る**: 目標ごとに明確な数値を 1 つ選び、成果が定性的な場合は OKR を使いましょう。
- **可能ならライブ データを接続する**: ダッシュボード連携目標は自動更新され、ステータスも自動判定されるため、チェックイン作業を減らせます。
- **Total / Average / Latest を使い分ける**: 売上は積み上がりますが、コンバージョン率や人員数は積み上がりません。
- **現実的なチェックイン頻度を設定する**: 四半期目標には週次、年次目標には月次が適しています。
- **Key Result の Impact を活用する**: 重要な結果は **High** にして、OKR が本当に重要な内容を反映するようにしましょう。
