# Microsoft Ads

[分析] の *Microsoft Ads* データ ソース コネクターを使用すると、Microsoft の広告データを Slingshot に取り込むことができます。**広告アカウント**のデータを使用してダッシュボードを作成し、キャンペーンのパフォーマンスを追跡できます。

## 前提条件

分析で *Microsoft Ads* データ ソースを使用する前に、次のことを確認してください:

- <a href="https://ads.microsoft.com/" target="_blank" rel="noopener">Microsoft Ads</a> アカウントを持っていること。
- アクセスできるデータを含む**広告アカウント**が少なくとも 1 つあること。
- 接続する**広告アカウント**のレポート データを表示する権限が Microsoft アカウントにあること。

## 新しい Microsoft Ads データ ソース アカウントの追加

Microsoft Ads データ ソースを**データ ソース** リストにすでに追加している場合は、この部分をスキップして次の「データの設定」に進むことができます。

Microsoft Ads データ ソースをリストに追加するには、次の手順に従います:

1. **[分析]** の **[+ ダッシュボード]** をクリックします。
2. **[+ データ ソース]** をクリックします。
3. **[データ ソース]** リストで **マーケティング、営業、CRM** の下にある *Microsoft Ads* を選択します。
4. Microsoft アカウントでサインインし、広告データへのアクセスを *Analytics* に許可します。

    > [!NOTE]
    > *Slingshot* で使用する Microsoft アカウントには、少なくとも 1 つの**広告アカウント**が関連付けられている必要があります。

5. 次のダイアログで分析する Microsoft 広告アカウントを選択し、**[選択して続行]** をクリックします。
6. 最後のダイアログで、アカウント名の変更、説明の追加、認証状態 (*Enterprise* ユーザー向け) の確認、詳細の編集を行います。**[データ ソースの追加]** を選択して完了します。

新しい Microsoft Ads アカウント接続が最近使用したデータ ソースに追加されます。

## データの設定

**[データ ソース]** リストから接続する Microsoft Ads アカウントを選択します。**[データ ソースの詳細]** ダイアログで構成を確認し、**[データの選択]** を選択します。

## 表示形式エディターでの作業

データ ソースを追加すると、*表示形式エディター*が開きます。既定では *柱状* 表示形式が選択されます。必要に応じて、ドロップダウン メニューから別のチャート タイプを選択できます。

表示形式の準備ができたら、ダッシュボードを **[分析]** ⇒ **[ダッシュボード]**、ワークスペース、またはプロジェクトに保存します。

データ ソースの詳細については、[データ ソース](../../datasources/overview.md)を参照してください。
