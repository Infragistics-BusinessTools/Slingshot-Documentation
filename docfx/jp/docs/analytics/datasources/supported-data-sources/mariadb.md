# MariaDB

> [!NOTE]
> **Web の制限**。*Analytics Web* アプリでは、公的にアクセス可能な MariaDB アドレスにのみ接続できます。MariaDB アドレスが一般公開に制限されている場合 (プライベートまたは会社のイントラネットでホストされているなど)、*Analytics Desktop*、*iOS*、または *Android* を使用して接続できます。Analytics を実行しているデバイスは、この MariaDB アドレスにアクセスできる必要があります。この制限は、*Analytics Embedded* には適用されません。

## MariaDB への接続

MariaDB サーバー データ ソースを設定するには、以下の情報を入力してください。

1. [**サーバー**](#サーバー情報を見つける方法): コンピューター名またはサーバーを実行しているコンピューターに割り当てられた IP アドレス。

2.  **ポート**: 該当する場合、サーバー ポートの詳細。情報が入力されない場合、Analytics はデフォルトでヒント テキスト (3306) のポートに接続します。

3.  **資格情報**: [資格情報] を選択した後、MariaDB サーバーの資格情報を入力するか、既存の資格情報 (適用可能な場合) を選択できます。

      - **ユーザー名**: MariaDB サーバーのユーザー アカウントまたはドメイン名。

      - **パスワード**: MariaDB サーバーにアクセスするためのパスワード。

      - **エイリアス**: データ ソース アカウントの名前。前のダイアログのアカウント リストに表示されます。

    準備ができたら、**[追加]** を選択し、次に **[サーバーの追加]** を選択します。

## サーバー情報を見つける方法

以下の手順に従ってサーバーを見つけることができます。コマンドはサーバーで実行する必要があります。

| WINDOWS                                                                                                         | LINUX                                                                                                         | MAC                                                                  |
| --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 1\. ファイル エクスプローラーを開きます。                                                                               | 1\. ターミナルを開きます。                                                                                          | 1\. システム設定を開きます。                                               |
| 2\. マイ コンピューターを右クリック \> [プロパティ]。                                                                       | 2\. **hostname** と入力します。                                                                                   | 2\. [共有] セクションに移動します。                                          |
| ホスト名は、*[コンピューター名、ドメイン、およびワークグループの設定]* セクションの "コンピューター名" として表示されます。 | ホスト名は DNS ドメイン名と共に表示されます。Analytics には **ホスト名** のみを入力してください。 | ホスト名は上部の "コンピューター名" フィールドに表示されます。 |

IP アドレスを調べるには、以下の手順に従ってください。コマンドはサーバーで実行する必要があります。

| WINDOWS                              | LINUX                             | MAC                                                           |
| ------------------------------------ | --------------------------------- | ------------------------------------------------------------- |
| 1\. コマンド プロンプトを開きます。           | 1\. ターミナルを開きます。              | 1\. ネットワーク アプリを起動します。                                  |
| 2\. **ipconfig** と入力します。             | 2\. **ip addr** と入力します。           | 2\. 接続を選択します。                                               |
| **IPv4 アドレス** が IP アドレスです。 | **Inet addr** が IP アドレスです。 | **IP アドレス** フィールドに必要な情報が表示されます。 |

## データの設定

Analytics では、テーブル全体から MariaDB データを取得できます。また、1 つまたは複数のテーブルからデータのサブセットを返す特定のビューを選択することもできます。

ビューと MariaDB の詳細については、<a href="https://mariadb.com/kb/en/views/" target="_blank">こちらのドキュメント ページ</a>をご覧ください。

## 表示形式エディターでの作業

テーブルまたはビューを選択すると、*表示形式エディター*に移動します。ここでダッシュボードを構築できます。デフォルトでは、*柱状*の表示形式が選択されています。別のグラフの種類を選択するには、それをクリックします。

表示形式エディターの準備ができたら、ダッシュボードを **[My Analytics]** ⇒ **[マイ ダッシュボード]** または特定のワークスペースに保存できます。
