# MariaDB

> [!NOTE]
> **Web での制限事項**。*Analytics Web* アプリでは、公開されている MariaDB アドレスにのみ接続できます。MariaDB アドレスが一般公開されていない場合（プライベートや企業のイントラネットでホストされている場合など）は、*Analytics Desktop*、*iOS*、または *Android* を使用して接続できます。Analytics を実行しているデバイスがその MariaDB アドレスにアクセスできる必要があります。この制限は *Analytics Embedded* には適用されません。

## MariaDB への接続

MariaDB サーバー データ ソースを設定するには、以下の情報を入力してください:

1. [**サーバー**](#how-to-find-your-server-information): サーバーが実行されているコンピューターに割り当てられたコンピューター名または IP アドレス。

2.  **ポート**: 該当する場合、サーバーのポートの詳細。情報を入力しない場合、Analytics はデフォルトでヒント テキストのポート（3306）に接続します。

3.  **認証情報**: *[認証情報]* を選択すると、MariaDB サーバーの認証情報を入力するか、該当する場合は既存の認証情報を選択できます。

      - **ユーザー名**: MariaDB サーバーのユーザー アカウントまたはドメイン名。

      - **パスワード**: MariaDB サーバーへのアクセス パスワード。

      - **エイリアス**: データ ソース アカウントの名前。前のダイアログのアカウント リストに表示されます。

    準備ができたら **[追加]** を選択し、**[サーバーを追加]** を選択します。

## サーバー情報の確認方法

以下の手順に従ってサーバーを確認できます。コマンドはサーバー上で実行する必要があることに注意してください。

| WINDOWS                                                                                                         | LINUX                                                                                                         | MAC                                                                  |
| --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 1\. ファイル エクスプローラーを開きます。                                                                                     | 1\. ターミナルを開きます。                                                                                          | 1\. システム設定を開きます。                                            |
| 2\. マイ コンピューターを右クリックして [プロパティ] を選択します。                                                                   | 2\. **hostname** と入力します。                                                                                      | 2\. [共有] セクションに移動します。                                 |
| ホスト名は *[コンピューター名、ドメイン、ワークグループの設定]* セクションの「コンピューター名」として表示されます。 | ホスト名は DNS ドメイン名とともに表示されます。Analytics には **ホスト名** のみを入力するようにしてください。 | ホスト名は上部の「コンピューター名」フィールドに表示されます。 |

以下の手順に従って *IP アドレス*を確認できます。コマンドはサーバー上で実行する必要があることに注意してください。

| WINDOWS                              | LINUX                             | MAC                                                           |
| ------------------------------------ | --------------------------------- | ------------------------------------------------------------- |
| 1\. コマンド プロンプトを開きます。           | 1\. ターミナルを開きます。              | 1\. ネットワーク アプリを起動します。                                  |
| 2\. **ipconfig** と入力します。             | 2\. **ip addr** と入力します。           | 2\. 接続を選択します。                                   |
| **IPv4 アドレス**が IP アドレスです。 | **Inet addr** が IP アドレスです。 | **IP アドレス** フィールドに必要な情報があります。 |

## データの設定

Analytics を使用すると、テーブル全体から MariaDB データを取得できます。テーブルまたはテーブルのセットからデータのサブセットを返す特定のビューを選択することもできます。

ビューと MariaDB の詳細については、<a href="https://mariadb.com/kb/en/views/" target="_blank">このドキュメント ページ</a>を参照してください。

## ビジュアライゼーション エディターでの作業

テーブルまたはビューを選択すると、*ビジュアライゼーション エディター*に移動します。ここでダッシュボードを構築できます。デフォルトでは*列*ビジュアライゼーションが選択されています。それを選択することで別のグラフ タイプを選択できます。

ビジュアライゼーション エディターの準備ができたら、ダッシュボードを **マイ アナリティクス** ⇒ **マイ ダッシュボード**または特定のワークスペースに保存できます。
