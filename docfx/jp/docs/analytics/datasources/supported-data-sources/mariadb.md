# MariaDB

> [!NOTE]
> **Web の制限**。*Analytics Web* アプリでは、公的にアクセス可能な MariaDB アドレスにのみ接続できます。MariaDB アドレスが一般公開 (プライベートまたは会社のイントラネットでホストされているなど) に制限されている場合は、*Analytics Desktop*、*iOS*、または *Android* を使用して接続できます。Analytics を実行しているデバイスは、この MariaDB アドレスにアクセスできる必要があります。この制限は、*Analytics Embedded* には適用されません。

## MariaDB への接続

MariaDB サーバー データ ソースを構成するには、以下の情報を入力します:

1. [**サーバー**](#サーバー情報を見つける方法): サーバーが実行されているコンピューターに割り当てられたコンピューター名または IP アドレス。

2.  **ポート**: 該当する場合、サーバー ポートの詳細。情報が入力されない場合、Analytics はデフォルトでヒント テキスト (3306) のポートに接続します。

3.  **資格情報**: *[資格情報]* を選択した後、MariaDB サーバーの資格情報を入力するか、既存の資格情報 (該当する場合) を選択できます。

      - **ユーザー名**: MariaDB サーバーのユーザー アカウントまたはドメインの名前。

      - **パスワード**: MariaDB サーバーのパスワード。

      - **エイリアス**: データ ソース アカウントの名前。以前のダイアログのアカウントのリストに表示されます。

    準備ができたら、**[追加]** を選択してから **[サーバーを追加]** を選択します。

## サーバー情報を見つける方法

以下の手順でサーバーを確認できます。コマンドはサーバーで実行する必要があることに注意してください。

| WINDOWS                                                                                                         | LINUX                                                                                                         | MAC                                                                  |
| --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 1\. ファイル エクスプローラーを開きます。                                                                                     | 1\. ターミナルを開きます。                                                                                          | 1\. システム環境設定を開きます。                                         |
| 2\. マイコンピューターを右クリックして [プロパティ] を選択します。                                                                   | 2\. **hostname** と入力します。                                                                                     | 2\. [共有] セクションに移動します。                                 |
| ホスト名は *[コンピューター名、ドメイン、ワークグループの設定]* の [コンピューター名] として表示されます。 | ホスト名は DNS ドメイン名と共に表示されます。Analytics には **ホスト名** のみを含めるようにしてください。 | ホスト名は上部の [コンピューター名] フィールドに表示されます。 |

以下の手順で *IP アドレス* を確認できます。コマンドはサーバーで実行する必要があることに注意してください。

| WINDOWS                              | LINUX                             | MAC                                                           |
| ------------------------------------ | --------------------------------- | ------------------------------------------------------------- |
| 1\. コマンド プロンプトを開きます。           | 1\. ターミナルを開きます。              | 1\. ネットワーク アプリを起動します。                                  |
| 2\. **ipconfig** と入力します。             | 2\. **ip addr** と入力します。           | 2\. 接続を選択します。                                               |
| **IPv4 アドレス** が IP アドレスです。 | **Inet addr** が IP アドレスです。 | **IP アドレス** フィールドに必要な情報があります。 |

## データの設定

Analytics を使用すると、テーブル全体から MariaDB データを取得できます。テーブルまたは一連のテーブルからデータのサブセットを返す特定のビューを選択することもできます。

ビューと MariaDB の詳細については、<a href="https://mariadb.com/kb/en/views/" target="_blank">こちらのドキュメント ページ</a>をご覧ください。

## 表示形式エディターでの作業

テーブルまたはビューを選択すると、*表示形式エディター*に移動します。ここでダッシュボードを作成できます。デフォルトでは、*縦棒*表示形式が選択されています。これを選択して別のグラフの種類を選択できます。

表示形式エディターの設定が完了したら、ダッシュボードを **マイ アナリティクス** ⇒ **マイ ダッシュボード** または特定のワークスペースに保存できます。
