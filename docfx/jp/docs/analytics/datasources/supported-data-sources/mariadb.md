# MariaDB

> [!NOTE]
> **Web での制限事項。** *Analytics Web* アプリでは、公開アクセス可能な MariaDB アドレスにのみ接続できます。MariaDB アドレスが一般公開に制限されている場合 (プライベートまたは会社のイントラネットでホストされているなど)、*Analytics Desktop*、*iOS*、または *Android* を使用して接続できます。Analytics を実行しているデバイスがこの MariaDB アドレスにアクセスできる必要があります。この制限は *Analytics Embedded* には適用されません。

## MariaDB への接続

MariaDB サーバー データ ソースを設定するには、次の情報を入力してください:

1. [**サーバー**](#サーバー情報の確認方法): サーバーが実行されているコンピューターに割り当てられたコンピューター名または IP アドレス。

2.  **ポート**: 該当する場合は、サーバーのポートの詳細を入力します。情報が入力されていない場合、Analytics はデフォルトでヒント テキストのポート (3306) に接続します。

3.  **資格情報**: *[資格情報]* を選択すると、MariaDB サーバーの資格情報を入力するか、該当する場合は既存の資格情報を選択できます。

      - **ユーザー名**: MariaDB サーバーのユーザー アカウントまたはドメイン名。

      - **パスワード**: MariaDB サーバーへのアクセス パスワード。

      - **エイリアス**: データ ソース アカウントの名前。前のダイアログのアカウントのリストに表示されます。

    準備ができたら、**[追加]** を選択し、次に **[サーバーの追加]** を選択します。

## サーバー情報の確認方法

以下の手順に従ってサーバーを見つけることができます。コマンドはサーバー上で実行する必要があります。

| WINDOWS                                                                                                         | LINUX                                                                                                         | MAC                                                                  |
| --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 1\. ファイル エクスプローラーを開きます。                                                                                     | 1\. ターミナルを開きます。                                                                                          | 1\. システム設定を開きます。                                            |
| 2\. [マイ コンピューター] を右クリック \> [プロパティ]。                                                                   | 2\. **hostname** と入力します。                                                                                      | 2\. [共有] セクションに移動します。                                                 |
| ホスト名は *[コンピューター名、ドメイン、ワークグループの設定]* セクションの "コンピューター名" として表示されます。 | ホスト名は DNS ドメイン名とともに表示されます。Analytics には **ホスト名** のみを含めるようにしてください。 | ホスト名は上部の "コンピューター名" フィールドに表示されます。 |

以下の手順に従って *IP アドレス*を見つけることができます。コマンドはサーバー上で実行する必要があります。

| WINDOWS                              | LINUX                             | MAC                                                           |
| ------------------------------------ | --------------------------------- | ------------------------------------------------------------- |
| 1\. コマンド プロンプトを開きます。           | 1\. ターミナルを開きます。              | 1\. ネットワーク アプリを起動します。                                  |
| 2\. **ipconfig** と入力します。             | 2\. **ip addr** と入力します。           | 2\. 接続を選択します。                                                   |
| **IPv4 アドレス**が IP アドレスです。 | **Inet addr** が IP アドレスです。 | **[IP アドレス]** フィールドに必要な情報が表示されます。 |

## データの設定

Analytics を使用すると、テーブル全体から MariaDB データを取得できます。テーブルまたは一連のテーブルからデータのサブセットを返す特定のビューを選択することもできます。

ビューと MariaDB の詳細については、<a href="https://mariadb.com/kb/en/views/" target="_blank">このドキュメント ページ</a>をご覧ください。

## 表示形式エディターでの作業

テーブルまたはビューを選択すると、*表示形式エディター*が表示されます。ここでダッシュボードを作成できます。デフォルトでは、*柱状*表示形式が選択されています。それを選択して、別のグラフの種類を選択できます。

表示形式エディターの準備ができたら、ダッシュボードを **[分析]** ⇒ **[ダッシュボード]** または特定のワークスペースに保存できます。
