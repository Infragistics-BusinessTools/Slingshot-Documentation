# YouTube

YouTube データ ソースを使用すると、YouTube チャンネルのデータを Slingshot に接続できます。インサイトに富んだダッシュボードにより、動画のパフォーマンス、視聴者のエンゲージメント、チャンネルの成長を追跡できます。

## YouTube を Slingshot に接続する

*YouTube* データ ソースをリストに追加するには、以下の手順に従ってください:

1.	ダッシュボード リストで **[+ ダッシュボード]** ボタンをクリックまたはタップします。

2. **[空のダッシュボード]** を選択します。

3.	**[+ データ ソース]** ボタンをクリックします。

4.	**[データ ソース]** リストから **[YouTube]** を選択します。

5.	**Google アカウント**でログインするように求められます。複数の YouTube チャンネルを管理している場合は、分析したいチャンネルに関連付けられているアカウントを選択してください。

6.	ダイアログが開き、データ ソースの名前を変更したり、説明を追加したり、データ ソースが[認定されて](../../../certifications.md)いるかどうかを確認したり、詳細を編集したりできます。

7. ダッシュボードに使用するチャンネル データを選択し、**[データの選択]** をクリックします。

## データの設定

**YouTube** に接続した後、次の操作を行う必要があります。

1.	アカウントを追加します。1 つ以上の YouTube チャンネルから選択できます。分析したいチャンネルを選択し、**[選択して続行]** をクリックまたはタップします。

2.	**データ ソース**を追加します。データ ソースを追加する前に、アカウント名を変更し、適切な説明を追加し、データ ソースが認定済みかどうか (**Enterprise** ユーザー向け) を確認し、詳細を編集できます。

3.	テーブルを選択します。

## 表示形式エディターでの作業

テーブルを選択すると、**表示形式エディター**が表示されます。ここでは、テーブル内のデータを使用してダッシュボードを作成できます。

YouTube データは、表示形式の作成に使用できる 2 つのカテゴリに分類されています。

- **ディメンション**には、質的データ (動画タイトル、公開日など) が含まれます。

- **メジャー**は数値データで構成されます (視聴回数、いいね、コメント、視聴時間など)。

>[!NOTE] デフォルトでは、**柱状**チャートが表示されます。それを選択して、別のチャート タイプを選択できます。

## 日付範囲データ フィルター

特定の日付範囲を選択して、データをフィルタリングできます。データ フィルターは削除できませんが、デフォルトの日付範囲 (*過去 7 日間*) は変更できることに注意してください。

日付範囲を変更するには、フィルターをクリックしてから、右上隅の矢印をクリックします。

## 設定

選択したチャート タイプに応じて、設定でさまざまな変更を行うことができます。[こちら](../../data-visualizations/overview.md)の表示形式エディター セクションで、さまざまなチャート タイプの詳細を確認できます。

**表示形式エディター**の準備ができたら、ダッシュボードを **[分析]** ⇒ **[ダッシュボード]**、特定のワークスペース またはプロジェクトに保存できます。
