# YouTube

YouTube データ ソースを使用すると、*YouTube チャンネル*のデータを Slingshot に接続できます。チャンネル アナリティクスを使用して、インサイトに満ちたダッシュボードを作成し、動画コンテンツのパフォーマンス、オーディエンス エンゲージメント、チャンネルの成長を測定できます。

## 前提条件

分析で *YouTube* データ ソースを使用する前に、次のことを確認してください:

- Google アカウントに関連付けられた <a href="https://support.google.com/youtube/answer/1646861" target="_blank">YouTube チャンネル</a>を持っていること。

- 接続するチャンネルの <a href="https://studio.youtube.com" target="_blank">YouTube Studio</a> へのアクセス権を持っていること。

## YouTube アカウントを Slingshot に接続する

*YouTube* データ ソースをリストに追加するには、以下の手順に従ってください:

1. **[分析]** セクションで **[ダッシュボード]** に移動し、**[+ダッシュボードの作成]** をクリックします。

2. **[+データ ソース]** ボタンをクリックします。

3. データ ソースとして **[YouTube Analytics]** を選択します。データ ソース リストの **[ソーシャル メディア]** の下に表示されます。

4. Google のログイン画面が表示されます。ログイン資格情報を入力し、**[サインイン]** をクリックします。

5. 承認プロンプトが表示されます。**[許可]** をクリックして、Slingshot が YouTube データにアクセスできるようにします。

6. アカウントに複数の YouTube チャンネルが関連付けられている場合は、分析するチャンネルを選択します。

7. 開いたダイアログで、データ ソース名を変更し、説明を追加し、データ ソースが[認定済み](../../../certifications.md)かどうかを確認し (*Enterprise* ユーザーが利用可能)、詳細を編集できます。**[データ ソースの追加]** をクリックしてプロセスを完了します。

> [!NOTE]
> ログインすると、データ ソースを削除しない限り、後で同じアカウントを使用して別の表示形式を作成できます。

## データの設定

**[データ ソース]** リストから、接続する YouTube アカウントを選択します。[データ ソースの詳細] ダイアログが表示され、データを確認して設定できます。

ここに、次のデータ ソースの詳細があります:

- 種類と名前

- 説明

- [認証](../../../certifications.md)

- データ ソースを追加したユーザーと日時

- 最後に変更したユーザーと日時

- アクセス権を持つユーザーとワークスペース

- データが更新される頻度。期間を変更するには、右側のドロップダウン メニューを選択します。

準備ができたら、**[データの選択]** をクリックして *表示形式エディター*に進みます。

## 表示形式エディターでの作業

データ ソースを追加すると、*表示形式エディター*が表示されます。

クエリ フィールドに 2 つのセクションが表示されます:

- **ディメンション** (ピンク色の面を持つキューブ アイコンで表示): ディメンションはデータの属性です。たとえば、*動画タイトル*ディメンションはチャンネル上の動画のタイトルを表します。

- **メジャー** (*123* アイコンで表示): メジャーは数値データで構成されます。たとえば、チャンネルの*再生回数*、*視聴時間*、*高評価*、*コメント*、および*新規登録者*を追跡できます。

デフォルトでは、*柱状*の表示形式が選択されています。それをクリックすると、ドロップダウン メニューから別のグラフの種類を選択できます。

## 日付範囲データ フィルター

特定の日付範囲を選択してデータをフィルタリングできます。日付フィルターはデフォルトで *直近 28 日間*に設定されています。

日付範囲を変更するには、フィルターをクリックし、右上隅の矢印をクリックして、ドロップダウン メニューから日付範囲を選択します。最初のオプションをクリックして、カスタム日付範囲を作成することもできます。

> [!NOTE]
> 日付範囲フィルターは削除できませんが、デフォルトの日付範囲はいつでも変更できます。

## 設定

選択したグラフの種類に応じて、設定でさまざまな変更を加えることができます。さまざまなグラフの種類の詳細については、[こちら](../../data-visualizations/overview.md)のデータ表示形式セクションをご確認ください。

表示形式エディターの準備ができたら、ダッシュボードを **[分析]** ⇒ **[ダッシュボード]**、特定のワークスペース、またはプロジェクトに保存できます。

データ ソースの詳細については、[こちら](../../datasources/overview.md)を参照してください。
