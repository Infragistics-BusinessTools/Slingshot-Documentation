# YouTube

YouTube データ ソースを使用すると、*YouTube チャンネル*のデータを Slingshot に接続できます。チャンネルのアナリティクスを使用して、洞察力のあるダッシュボードを作成し、動画コンテンツのパフォーマンス、オーディエンスのエンゲージメント、チャンネルの成長を測定します。

## 前提条件

Analytics で *YouTube* データ ソースを使用する前に、以下を確認してください:

- Google アカウントに関連付けられた <a href="https://support.google.com/youtube/answer/1646861" target="_blank">YouTube チャンネル</a>があること。

- 接続するチャンネルの <a href="https://studio.youtube.com" target="_blank">YouTube Studio</a> にアクセスできること。

## YouTube アカウントを Slingshot に接続する

*YouTube* データ ソースをリストに追加するには、以下の手順に従います:

1. **[マイ アナリティクス]** セクションを見つけ、**[ダッシュボード]** に移動して **[+ ダッシュボードを作成]** をクリックします。

2. **[+ データ ソース]** ボタンをクリックします。

3. データ ソースとして **[YouTube Analytics]** を選択します。データ ソース リストの **[ソーシャル メディア]** の下にあります。

4. Google のログイン画面が表示されます。ログイン資格情報を入力して *[サインイン]* をクリックします。

5. 認証プロンプトが表示されます。*[許可]* をクリックして、Slingshot が YouTube データにアクセスできるようにします。

6. アカウントに複数の YouTube チャンネルが関連付けられている場合は、分析するチャンネルを選択します。

7. 開いたダイアログでは、データ ソース名の変更、説明の追加、データ ソースが[認定](../../../certifications.md)されているかどうかの確認 (*Enterprise* ユーザーが利用可能)、詳細の編集ができます。**[データ ソースを追加]** をクリックしてプロセスを完了します。

> [!NOTE]
> ログイン後は、データ ソースを削除しない限り、同じアカウントを後で別の表示形式の作成に使用できます。

## データの設定

*データ ソース* リストから、接続する YouTube アカウントを選択します。*データ ソースの詳細* ダイアログが表示され、データを確認および設定できます。

ここには以下のデータ ソースの詳細があります:

- タイプと名前

- 説明

- [認定](../../../certifications.md)

- データ ソースを追加したユーザーと日時

- 最後に変更したユーザーと日時

- アクセス権を持つユーザーとワークスペース

- データの更新頻度。時間を変更するには、右側のドロップダウン メニューを選択します。

準備ができたら、**[データを選択]** をクリックして *表示形式エディター* に進みます。

## 表示形式エディターでの作業

データ ソースが追加されると、*表示形式エディター*に移動します。

それぞれのクエリ フィールドに 2 つのセクションが表示されます:

- **ディメンション** (ピンクの面を持つキューブ アイコンで表示): ディメンションはデータの属性です。たとえば、ディメンション *動画のタイトル* はチャンネルの動画のタイトルを表します。

- **メジャー** (*123* アイコンで表示): メジャーは数値データで構成されます。たとえば、チャンネルの *再生回数*、*視聴時間*、*高評価数*、*コメント数*、*チャンネル登録者増加数* を追跡できます。

デフォルトでは、*縦棒*表示形式が選択されています。それをクリックして、ドロップダウン メニューから別のグラフの種類を選択します。

## 日付範囲データ フィルター

特定の日付範囲を選択してデータをフィルタリングできます。日付フィルターはデフォルトで *過去 28 日間* に設定されています。

日付範囲を変更するには、フィルターをクリックし、右上の矢印をクリックしてドロップダウン メニューから日付範囲を選択します。最初のオプションをクリックしてカスタム日付範囲を作成することもできます。

> [!NOTE]
> 日付範囲フィルターは削除できませんが、デフォルトの日付範囲はいつでも変更できます。

## 設定

選択したグラフの種類に応じて、設定でさまざまな変更ができます。さまざまなグラフの種類については、データ表示形式セクションの[こちら](../../data-visualizations/overview.md)で詳細を確認できます。

表示形式エディターの設定が完了したら、ダッシュボードを **マイ アナリティクス** ⇒ **マイ ダッシュボード**、特定のワークスペース、またはプロジェクトに保存できます。

データ ソースの詳細については、[こちら](../../datasources/overview.md)をご覧ください。
