# YouTube

YouTube データ ソースを使用すると、*YouTube チャンネル*のデータを Slingshot に接続できます。チャンネル アナリティクスを使用してインサイトに富んだダッシュボードを作成し、動画コンテンツのパフォーマンス、視聴者エンゲージメント、チャンネルの成長を測定できます。

## 前提条件

Analytics で *YouTube* データ ソースを使用する前に、以下を確認してください。

- Google アカウントに関連付けられた <a href="https://support.google.com/youtube/answer/1646861" target="_blank">YouTube チャンネル</a>があること。

- 接続するチャンネルの <a href="https://studio.youtube.com" target="_blank">YouTube Studio</a> へのアクセス権があること。

## YouTube アカウントを Slingshot に接続する

*YouTube* データ ソースをリストに追加するには、以下の手順に従います。

1. **[分析]** セクションで **[ダッシュボード]** に移動し、**[+ ダッシュボードの作成]** をクリックします。

2. **[+ データ ソース]** ボタンをクリックします。

3. データ ソースとして **[YouTube Analytics]** を選択します。データ ソース一覧の **[ソーシャル メディア]** の下にあります。

4. Google のログイン画面が表示されます。ログイン資格情報を入力し、*[ログイン]* をクリックします。

5. 認証プロンプトが表示されます。*[許可]* をクリックして、Slingshot が YouTube データにアクセスできるようにします。

6. アカウントに複数の YouTube チャンネルが関連付けられている場合は、分析するチャンネルを選択します。

7. 表示されるダイアログで、データ ソース名を変更したり、説明を追加したり、データ ソースが[認定済み](../../../certifications.md) (*Enterprise* ユーザーが利用可能) かどうかを確認したり、詳細を編集したりできます。**[データ ソースの追加]** をクリックしてプロセスを完了します。

> [!NOTE]
> ログイン後は、データ ソースを削除しない限り、同じアカウントを使用して後で別の表示形式を作成できます。

## データの設定

*[データ ソース]* リストから接続する YouTube アカウントを選択します。*データ ソースの詳細*ダイアログが表示され、データを確認および設定できます。

ここでは、以下のデータ ソースの詳細が表示されます。

- タイプと名前

- 説明

- [認定](../../../certifications.md)

- データ ソースを追加したユーザーと日時

- 最後に変更したユーザーと日時

- アクセス権を持つユーザーとワークスペース

- データが更新される頻度。期間を変更するには、右側のドロップダウン メニューを選択します。

準備ができたら、**[データの選択]** をクリックして*表示形式エディター*に進みます。

## 表示形式エディターでの作業

データ ソースが追加されると、*表示形式エディター*に移動します。

それぞれのクエリ フィールドに 2 つのセクションが表示されます。

- **ディメンション** (ピンク色の面を持つキューブ アイコンで表示): ディメンションはデータの属性です。たとえば、ディメンション *[動画タイトル]* はチャンネルの動画タイトルを表します。

- **メジャー** (*123* アイコンで表示): メジャーは数値データで構成されます。たとえば、チャンネルの*再生回数*、*視聴時間*、*高評価数*、*コメント数*、*登録者増加数*を追跡できます。

デフォルトでは、*柱状*表示形式が選択されます。クリックしてドロップダウン メニューから別のチャート タイプを選択できます。

## 日付範囲データ フィルター

特定の日付範囲を選択してデータをフィルタリングできます。日付フィルターはデフォルトで*過去 28 日間*に設定されています。

日付範囲を変更するには、フィルターをクリックし、右上隅の矢印をクリックしてドロップダウン メニューから日付範囲を選択します。最初のオプションをクリックしてカスタム日付範囲を作成することもできます。

> [!NOTE]
> 日付範囲フィルターは削除できませんが、デフォルトの日付範囲はいつでも変更できます。

## 設定

選択したチャート タイプに応じて、設定でさまざまな変更を行うことができます。さまざまなチャート タイプの詳細については、データ表示形式セクションの[こちら](../../data-visualizations/overview.md)をご覧ください。

表示形式エディターの準備ができたら、ダッシュボードを **[分析]** ⇒ **[ダッシュボード]**、特定のワークスペース、またはプロジェクトに保存できます。

データ ソースの詳細については、[こちら](../../datasources/overview.md)をご覧ください。
