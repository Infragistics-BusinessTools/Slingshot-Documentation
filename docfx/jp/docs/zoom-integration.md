# Zoom インテグレーション

Zoom インテグレーションを使用すると、Slingshot を離れることなく Zoom 通話を開始できます。プライベート チャットから、Slingshot がお客様の代わりにインスタント Zoom ミーティングを作成し、参加リンクを会話に直接投稿します。これにより、全員が 1 回のクリック/タップで通話に参加できます。

## Zoom アプリを追加する

事前に何かを設定する必要はありません — Slingshot は、初めて使用したときに Zoom アカウントを接続します。

1. チームメートとのプライベート チャットを開きます。

2. チャット ヘッダーの **[通話]** ボタンをクリック/タップします。

3. **[リンクを作成]** を選択し、次に **[Zoom を使用]** を選択します。

4. Zoom のサインイン ページでブラウザー ウィンドウが開きます。Zoom アカウントでサインインします。

5. 要求された権限を確認し、**[許可]** をクリック/タップします。Slingshot が Zoom に要求する権限は 2 つのみです: Zoom プロフィールの表示 (接続されているアカウントを表示するため) とミーティングの作成です。

6. Slingshot に戻り、Zoom アカウントが接続されます。

> [!NOTE]
> このインテグレーションはすべての Zoom アカウントで動作します — 有料の Zoom プランは必要ありません。Zoom ミーティングは、お客様自身の Zoom プランの設定と制限を維持します。

接続中に問題が発生した場合は、以下の[トラブルシューティング](#トラブルシューティング)をご覧ください。

## Zoom インテグレーションを使用する

Zoom アカウントが接続されると、通話を開始するのに数秒しかかかりません:

1. プライベート チャットで、**[通話]** ボタンをクリック/タップし、次に **[リンクを作成]** → **[Zoom を使用]** を選択します。

2. Slingshot がインスタント Zoom ミーティングを作成し、**[通話に参加]** カードを会話に投稿します。

3. チャット内の全員が **[通話に参加]** をクリック/タップして Zoom ミーティングを開くことができます。

Zoom へのサインインを再度求められることはありません — Slingshot は接続されたアカウントを記憶しています。接続されている Zoom アカウントは、**[設定]** → **[アプリ]** でいつでも確認できます。ここには Zoom エントリにアカウントの名前とメール アドレスが表示されます。

> [!NOTE]
> **Slingshot ヒント**: ミーティング リンクは通常の Zoom リンクです — Slingshot ユーザーでない参加者も、リンクを共有すれば参加できます。

### Slingshot が保存するデータ

Slingshot が保存するのは、Zoom アカウントの接続を維持するために必要な情報のみです: Zoom が Slingshot に発行するセキュアなアクセス資格情報と、接続にラベルを付けるための Zoom プロフィール名とメール アドレスです。Slingshot は、Zoom ミーティング、録画、連絡先、またはその他の Zoom データを読み取りません。

## Zoom アプリを削除する

Zoom アカウントは Slingshot からいつでも切断できます:

1. Slingshot で、**[設定]** → **[アプリ]** を開きます。

2. **[Zoom]** エントリを見つけ、**[削除]** (ゴミ箱) ボタンをクリック/タップします。

3. 削除を確認します。

インテグレーションを削除すると、Slingshot は保存されている Zoom 資格情報と Zoom アカウントの詳細を直ちに削除します。チャットに既に投稿されたミーティング リンクは引き続き機能します。ミーティングはお客様の Zoom アカウントに属しているため、Zoom ポータルからいつでも管理または削除できます。

Zoom 側からも Slingshot を削除するには、[Zoom App Marketplace](https://marketplace.zoom.us/) にサインインし、**[管理]** → **[追加済みアプリ]** を開き、**[Slingshot]** を見つけて **[削除]** をクリック/タップします。

後でプライベート チャットから再度 Zoom を使用する場合、Slingshot は Zoom へのサインインとアプリの再認証を求めます。

## トラブルシューティング

- **「オンライン ミーティングを生成できませんでした。」** — ミーティングを作成できませんでした。しばらくしてから再試行してください。それでも失敗する場合は、**[設定]** → **[アプリ]** で Zoom アプリを削除し、プライベート チャットから **[Zoom を使用]** を選択して再接続してください。

- **Zoom への再サインインが求められる。** — Zoom セッションの有効期限が切れました。サインインして **[許可]** をクリック/タップして再接続してください。チャットと以前のミーティング リンクには影響しません。

- **接続時にブラウザー ウィンドウが開かない。** — ブラウザーが Slingshot のポップアップを許可していることを確認してから、**[Zoom を使用]** を再度試してください。

その他の問題については、アプリ内フィードバック オプションからご連絡ください — [フィードバック](feedback.md)をご覧ください。
