# Zoom 連携

Zoom 連携を使用すると、Slingshot を離れずに Zoom 通話を開始できます。任意のプライベート チャットから、Slingshot が代理でインスタント Zoom 会議を作成し、会話内に参加リンクを投稿します。これにより、全員がワンクリック/タップで通話に参加できます。

## Zoom アプリを追加する

事前設定は不要です。初回利用時に Slingshot が Zoom アカウントを接続します。

1. チームメンバーとのプライベート チャットを開きます。

2. チャット ヘッダーの **call** ボタンをクリック/タップします。

3. **Create Link** を選択し、次に **Use Zoom** を選択します。

4. ブラウザー ウィンドウで Zoom のサインイン ページが開きます。Zoom アカウントでサインインします。

5. 要求されるアクセス許可を確認し、**Allow** をクリック/タップします。Slingshot が Zoom に求める権限は 2 つだけです。接続済みアカウントを表示するための Zoom プロファイルの参照権限と、会議を作成する権限です。

6. Slingshot に戻ると、Zoom アカウントの接続が完了しています。

> [!NOTE]
> この連携は任意の Zoom アカウントで使用でき、有料プランは不要です。Zoom 会議の設定と制限は、ご利用中の Zoom プランに従います。

接続時に問題が発生した場合は、以下の [トラブルシューティング](#トラブルシューティング) を参照してください。

## Zoom 連携を使用する

Zoom アカウントを接続すると、通話の開始は数秒で完了します。

1. プライベート チャットで **call** ボタンをクリック/タップし、**Create Link** → **Use Zoom** を選択します。

2. Slingshot がインスタント Zoom 会議を作成し、会話に **Join Call** カードを投稿します。

3. チャット内の全員が **Join Call** をクリック/タップして Zoom 会議を開けます。

Slingshot は接続済みアカウントを記憶するため、再度 Zoom サインインを求められることはありません。どの Zoom アカウントが接続されているかは、**Settings** → **Apps** でいつでも確認できます。Zoom の項目にアカウント名とメール アドレスが表示されます。

> [!NOTE]
> **Slingshot Tip**: 会議リンクは通常の Zoom リンクです。Slingshot ユーザーでない参加者にもリンクを共有すれば参加できます。

### Slingshot が保存する情報

Slingshot は、Zoom アカウント接続の維持に必要な情報のみを保存します。具体的には、Zoom が Slingshot に発行する安全なアクセス資格情報と、接続ラベル表示のための Zoom プロファイル名およびメール アドレスです。Slingshot は Zoom 会議、録画、連絡先、その他の Zoom データを読み取りません。

## Zoom アプリを削除する

Zoom アカウントはいつでも Slingshot から切断できます。

1. Slingshot で **Settings** → **Apps** を開きます。

2. **Zoom** 項目を見つけて **remove** (ごみ箱) ボタンをクリック/タップします。

3. 削除を確認します。

連携を削除すると、Slingshot は保存されていた Zoom 資格情報と Zoom アカウント情報を即時に削除します。すでにチャットに投稿済みの会議リンクは、会議があなたの Zoom アカウントに属しているため引き続き機能します。会議はいつでも Zoom ポータルで管理または削除できます。

Zoom 側でも Slingshot を削除するには、[Zoom App Marketplace](https://marketplace.zoom.us/) にサインインし、**Manage** → **Added Apps** を開き、**Slingshot** を見つけて **Remove** をクリック/タップします。

後でプライベート チャットから再度 Zoom を使う場合は、Zoom へのサインインとアプリの再承認を行うだけで利用を再開できます。

## トラブルシューティング

- **"Failed to generate online meeting."** 会議を作成できませんでした。少し待ってから再試行してください。失敗が続く場合は、**Settings** → **Apps** で Zoom アプリを削除し、プライベート チャットから **Use Zoom** を選択して再接続してください。

- **Zoom に再度サインインするよう求められる。** Zoom セッションの有効期限が切れています。サインインして **Allow** をクリック/タップし、再接続してください。チャットや既存の会議リンクには影響しません。

- **接続時にブラウザー ウィンドウが開かない。** ブラウザーで Slingshot のポップアップを許可してから、もう一度 **Use Zoom** を試してください。

その他の問題については、アプリ内のフィードバック オプションからお問い合わせください。[フィードバック](feedback.md) を参照してください。
