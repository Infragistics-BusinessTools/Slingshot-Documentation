# ChatGPT で Slingshot MCP に接続する

このガイドでは、Slingshot MCP サーバーを ChatGPT に接続する手順を説明します。接続後は、ChatGPT の自然言語を使用してタスクの作成と更新、ワークスペースの検索、ステータス更新の生成などを行えます。

## 前提条件

- ChatGPT Plus または Pro サブスクリプション (カスタム MCP コネクターに必要)
- Slingshot アカウント
- Slingshot MCP サーバー URL: `https://mcp.slingshotapp.io/mcp`

## 接続方法

**1. ChatGPT の設定を開く**

ChatGPT の右上隅にあるプロフィール アイコンをクリックし、**設定** を選択します。

**2. デベロッパー モードを有効にする**

設定で **コネクター** に移動し、**詳細設定** をクリックして **デベロッパー モード** を **オン** に切り替えます。

**3. Slingshot コネクターを追加する**

**コネクター** の下にある **作成** をクリックします。以下を入力します:

- **名前:** Slingshot
- **MCP サーバー URL:** `https://mcp.slingshotapp.io/mcp`

**作成** をクリックします。

**4. Slingshot で認証する**

プロンプトが表示されたら OAuth サインイン フローを完了して、ChatGPT が Slingshot アカウントにアクセスすることを承認します。

**5. チャットでコネクターを有効にする**

新しいチャットを開き、**+** アイコンをクリックして **その他** をクリックし、**デベロッパー ツール** を選択して会話で Slingshot コネクターを有効にします。

## 接続の確認

コネクターを有効にした状態で、次のようなプロンプトを試してみてください:

> *「今週期限の Slingshot タスクを一覧表示して。」*

Slingshot がデータで応答すれば、接続は正常に機能しています。

>[!NOTE]
>デベロッパー モードの切り替えは ChatGPT Plus および Pro アカウントでのみ利用できます。表示されない場合は、サブスクリプションを確認するか、最新バージョンの ChatGPT Web アプリを使用していることを確認してください。

## トラブルシューティング

- **デベロッパー モードの切り替えが表示されない場合** アカウントが ChatGPT Plus または Pro であることを確認し、Web アプリを更新してみてください。
- **認証に失敗した場合** コネクターを削除して再追加し、プロンプトが表示されたときに OAuth フローを再度完了してください。
- **ツールが表示されない場合** 現在のチャットの **デベロッパー ツール** メニューで Slingshot コネクターがオンになっていることを確認してください。
- **権限エラーが発生した場合** Slingshot アカウントが、クエリしているワークスペースまたはプロジェクトにアクセスできることを確認してください。
