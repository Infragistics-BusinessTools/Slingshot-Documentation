# CSV ファイルからタスクをインポートする

CSV タスク インポートを使用すると、スプレッドシート、他のプロジェクト管理ツール、または CSV にエクスポートできる任意のソースからタスクを Slingshot タスク リストに直接移動できます。Slingshot は列の種類を自動的に検出してタスク フィールドにマッピングするため、セットアップの時間を削減し、作業に集中できます。

> [!NOTE]
> CSV インポートは**ワークスペース オーナー**のみが利用できます。**[インポート]** オプションが表示されない場合は、ワークスペース オーナーに確認してください。

## タスクのインポート方法

### ステップ 1: インポートを開始する

CSV インポートを開始する方法は 2 つあります。

- **タスク リストから** — タスク リストのオーバーフロー メニューをクリック/タップし、**[インポート]** を選択します。タスクが追加される「インポート」という名前の新しいセクションが作成されます。
- **セクションから** — 特定のセクションのオーバーフロー メニューをクリック/タップし、**[インポート]** を選択します。タスクはそのセクションに直接追加されます。

> [!NOTE]
> タスク リスト メニューから複数回インポートすると、各インポートで増分名 (例: 「インポート」、「インポート 2」、「インポート 3」) の新しいセクションが作成されます。

### ステップ 2: ファイルをアップロードする

**[インポート]** を選択すると、ファイル ピッカーが開きます。`.csv` ファイルを選択すると、Slingshot が自動的に解析します。

CSV ファイルは以下のガイドラインに従ってください。

- **最初の行**には列ヘッダー (フィールド名) が含まれている必要があります。
- 後続の各行はタスクを表します。
- ファイルは最大 **50 列**および **2,000 行**まで対応しています。

### ステップ 3: マッピング グリッドを確認する

ファイルがアップロードされると、Slingshot は CSV データを列で整理した**マッピング グリッド**を表示します。各列ヘッダーには以下が表示されます。

- ファイルからの **CSV 列名**
- 検出されたフィールド タイプを表す**アイコン**
- フィールド マッピングを変更するためにクリック/タップできる**ドロップダウン**

Slingshot はデータを自動的に分析し、各 CSV 列を最も適合するタスク フィールドにマッピングします。たとえば、日付値を含む「期日」という名前の列は自動的に**期日**フィールドにマッピングされます。

#### Slingshot が自動的に検出するもの

| データ パターン | 検出されたフィールド タイプ |
|---|---|
| "true" / "false" 値 | **チェックボックス** |
| 日付値 | **日付** |
| 0 から 5 の数値 | **評価** |
| 0 から 100 の数値 | **手動進捗** |
| その他の数値 | **数値** |
| 長いテキスト (255 文字以上) | **長いテキスト** |
| 繰り返し値を持つ短いテキスト | **ドロップダウン** |
| その他すべて | **テキスト** |

タスク リストの既存のフィールドに一致しない列がある場合、Slingshot は見つかったデータに基づいて新しいカスタム フィールドの作成を提案します。提案されたフィールドは、インポートを確認したときにのみタスク リストに追加されます — 準備ができるまで何も変更されません。

> [!IMPORTANT]
> **Slingshot ヒント**: 列にデータがない場合、Slingshot はデフォルトで**テキスト**に設定しますが、列ヘッダーのドロップダウンを使用して任意のサポートされているフィールド タイプに手動で変更できます。

#### 列マッピングの調整

任意の列のマッピングを変更するには、ヘッダーをクリック/タップしてドロップダウンから別のフィールドを選択します。オプションには以下が含まれます。

- **既存のタスク フィールド** — _タイトル_、_ステータス_、_優先度_、_期日_、_担当者_、タスク リストのカスタム フィールドなど。
- **提案された新しいフィールド** — データに基づいて Slingshot が推奨するカスタム フィールド。
- **無視** — インポート中にこの列を完全にスキップします。無視された列はグリッドで薄く表示されます。

#### タスク タイプの選択

マッピング グリッドには上部に**タスク タイプ セレクター**があります。ワークスペースで複数のタスク タイプを使用している場合、それらを切り替えてマッピングに使用できるフィールドを変更できます。

> [!IMPORTANT]
> タスク タイプを変更すると、すべての列マッピングがリセットされます。CSV データは保持されます — フィールドの割り当てのみがクリアされるため、新しいタスク タイプのフィールドに再マッピングできます。

### ステップ 4: 不一致を解決する

列が**ドロップダウン**または**ラベル**フィールドにマッピングされており、CSV の値が既存のオプションに一致しない場合、その列ヘッダーに**警告アイコン**が表示されます。

警告アイコンをクリック/タップして**値マッピング**ダイアログを開き、以下の操作ができます。

- 認識されない値を既存のドロップダウンまたはラベル オプションに**マッピングする**
- **新しいオプションを追加する** — カラー ピッカーを使用してダイアログから直接カスタム カラーで新しいアイテムを作成する

ここで作成した新しいオプションは、インポートを確認したときにのみ保存されます。キャンセルした場合、既存のフィールドに何も変更されません。

### ステップ 5: 確認してインポートする

マッピングが完了したら、**[マッピングの適用]** をクリック/タップしてインポートを開始します。

> [!NOTE]
> **[マッピングの適用]** ボタンは、少なくとも 1 つの列が**タイトル**フィールドにマッピングされるまで無効になっています。すべてのタスクにタイトルが必要で、タイトル列はすべての行に値が必要です — 空白のセルを含む列はタイトルに使用できません。

未解決のドロップダウンまたはラベルの不一致がある場合、Slingshot は続行する前に値マッピング ダイアログを 1 つずつ案内します。

## インポートの進捗状況の追跡

インポートを確認すると、**進捗状況ダイアログ**にインポートのステータスがリアルタイムで表示されます。待つ必要はありません — このダイアログを閉じて Slingshot での作業を続けてください。画面の右下隅に小さな**フローティング進捗インジケーター**が表示されるため、状況を確認できます。

インポートが完了すると:

- **すべてのタスクが正常にインポートされた** — 作成されたタスクの総数のサマリーと、タスク リストに直接移動するための **[そこへ移動]** ボタンが表示されます。
- **一部のタスクにエラーがあった** — サマリーには成功したタスク数と、インポートできなかった行の詳細が表示されます。

> [!NOTE]
> 一度に実行できるインポートは 1 つだけです。別のインポートがすでに進行中のときに新しいインポートを開始しようとすると、Slingshot がお知らせします。

## インポート中のサブタスクの作成

CSV に**親タスクのタイトル**列を含めることで、タスク間の親子関係を設定できます。

インポート中にサブタスクを作成するには:

1. CSV の列の 1 つを**親タスクのタイトル**フィールド タイプにマッピングします。
2. 各行に、この列に親タスクの**正確なタイトル**を入力します。
3. 親タスクが CSV ファイルで子タスクの**上に**表示されていることを確認してください。
4. トップレベルのタスクの**親タスクのタイトル**列は空白のままにします。

> [!NOTE]
> サポートされるサブタスクのネストは 1 レベルのみです — サブタスク自体を別のサブタスクの親にすることはできません。

**CSV の例:**

| タイトル | ステータス | 親タスクのタイトル |
|---|---|---|
| ホームページのデザイン | 進行中 | |
| ワイヤーフレームの作成 | 未着手 | ホームページのデザイン |
| カラーパレットの選択 | 未着手 | ホームページのデザイン |
| API の構築 | 未着手 | |

この例では、「ワイヤーフレームの作成」と「カラーパレットの選択」は「ホームページのデザイン」のサブタスクになり、「API の構築」はトップレベルのタスクのままです。

## サポートされているフィールド

以下のタスク フィールドを CSV インポートで入力できます。

| フィールド | 注記 |
|---|---|
| **タイトル** | **必須。** すべての行に値が必要です。正確に 1 つの列がタイトルにマッピングされている必要があります。 |
| **ステータス** | オプション。ステータスにマッピングされた列がない場合、タスクはデフォルトで**未着手**になります。 |
| **説明** | オプション。 |
| **優先度** | オプション。 |
| **期日** | オプション。 |
| **開始日** | オプション。 |
| **担当者** | オプション。1 つのセル内にカンマで区切られた複数の担当者をサポートします。名前またはメール アドレスはワークスペース メンバーと照合されます。 |
| **ラベル** | オプション。 |
| **カスタム フィールド** | _テキスト_、_数値_、_日付_、_チェックボックス_、_評価_、_ドロップダウン_、_長いテキスト_、_手動進捗_、_メール_、_電話番号_、_人物_フィールドはすべてサポートされています。これらはタスク リストにそれらのタイプのカスタム フィールドを作成している場合にのみ適用されます。 |
| **親タスクのタイトル** | オプション。親子関係を確立します (上記参照)。 |

> [!NOTE]
> CSV インポートでは入力できないフィールドがあります。_添付ファイル_、_時間トラッキング_、_繰り返し_、_作成日_、_完了日_などです。

## スムーズなインポートのためのヒント

- **CSV の準備** — 最初の行に明確な列ヘッダーが含まれていることを確認してください。Slingshot はこれらを使用してフィールド マッピングを自動検出します。
- **タイトルを入力しておく** — _タイトル_列には空白のセルを含めることができません。インポートする前に空白を埋めてください。
- **一貫したドロップダウン値を使用する** — 既存のドロップダウン フィールドにインポートする場合は、CSV のオプション名を一致させて余分なマッピング手順を避けてください。
- **日付形式を確認する** — 標準的な日付形式は自動的に認識されます。
- **複数の値にはカンマを使用する** — _担当者_や_人物_、_メール_などの複数値カスタム フィールドでは、1 つのセルに複数の値を含める場合はカンマで区切ります (例: "alice@example.com, bob@example.com")。
- **日付範囲を分割する** — 日付範囲は単一フィールドとしてサポートされていません。代わりに個別の_開始日_と_終了日_の列を使用してください。

## 他のツールからのインポート

別のプロジェクト管理ツールにタスクがある場合は、CSV としてエクスポートして Slingshot にインポートできます。以下は最も一般的なツールの手順ガイドです。

### ClickUp からのインポート

ClickUp ではタスクを CSV にエクスポートできます。Slingshot のエクスポートを準備するには:

1. **ClickUp からエクスポート** — ClickUp でタスクを CSV にエクスポートします。プロンプトが表示されたら、インポート時に日付が正しく認識されるように日付の **ISO 形式**を選択します。
2. **サブタスクの準備** — ClickUp は各親タスクのサブタスク ID リストとしてサブタスク関係をエクスポートしますが、Slingshot はこれを直接読み取ることができません。Slingshot が理解できる形式に変換するには:
   - エクスポートされた CSV を Excel または Google スプレッドシートで開きます。
   - **親タスクのタイトル**という名前の新しい列を追加します。
   - 新しい列の最初のデータ行に以下の数式を入力し (すべての行にコピー):
     ```
     =IFERROR(INDEX($C:$C, MATCH("*"&TRIM(CLEAN(B2))&"*", $F:$F, 0)), "")
     ```
     列文字をファイルに合わせて調整します。
     - **B** = _タスク ID_ 列
     - **C** = _タスク名_ 列
     - **F** = _サブタスク ID_ 列
   - ファイルを CSV として保存します。
3. **Slingshot にインポート** — 上記の標準インポート手順に従います。マッピング グリッドを確認する際は、**親タスクのタイトル**列が**親タスクのタイトル**フィールド タイプにマッピングされていることを確認してください。

### Asana からのインポート

Asana のエクスポートにはサブタスク関係が含まれているため、プロセスは簡単です。

1. **Asana からエクスポート** — Asana でプロジェクトを CSV にエクスポートします。サブタスクは各サブタスクの親の名前を含む**親タスク**列と共に自動的にエクスポートされます。
2. **Slingshot にインポート** — 上記の標準インポート手順に従います。マッピング グリッドを確認する際は、**[親タスク]** 列を**親タスクのタイトル**フィールド タイプにマッピングします。Slingshot は自動的に親子関係を作成します。
