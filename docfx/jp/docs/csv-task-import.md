# CSV ファイルからのタスクのインポート

CSV タスク インポートを使用すると、スプレッドシート、他のプロジェクト管理ツール、または CSV にエクスポートするあらゆるソースからタスクを Slingshot のタスク リストに直接移動できます。Slingshot は列の種類を自動的に検出してタスク フィールドにマッピングするため、セットアップに時間をかけずに作業に集中できます。

> [!NOTE]
> CSV インポートは**ワークスペース オーナー**のみが使用できます。**インポート** オプションが表示されない場合は、ワークスペース オーナーに確認してください。

## タスクのインポート方法

### 手順 1: インポートを開始する

CSV インポートを開始する方法は 2 つあります:

- **タスク リストから** — タスク リストのオーバーフロー メニューをクリックまたはタップし、**[インポート]** を選択します。タスクが追加される「インポート」という新しいセクションが作成されます。
- **セクションから** — 特定のセクションのオーバーフロー メニューをクリックまたはタップし、**[インポート]** を選択します。タスクがそのセクションに直接追加されます。

> [!NOTE]
> タスク リスト メニューから複数回インポートすると、各インポートにインクリメントされた名前の新しいセクションが作成されます (例: 「インポート」、「インポート 2」、「インポート 3」)。

### 手順 2: ファイルをアップロードする

**[インポート]** を選択すると、ファイル ピッカーが開きます。`.csv` ファイルを選択すると、Slingshot が自動的に解析します。

CSV ファイルは次のガイドラインに従ってください:

- **最初の行**には列ヘッダー (フィールド名) を含める必要があります。
- 後続の各行はタスクを表します。
- ファイルには最大 **50 列**と **2,000 行**を含めることができます。

### 手順 3: マッピング グリッドを確認する

ファイルをアップロードすると、Slingshot は CSV データを列ごとに整理した**マッピング グリッド**を表示します。各列ヘッダーには次が表示されます:

- ファイルからの **CSV 列名**
- 検出されたフィールドの種類を示す**アイコン**
- フィールド マッピングを変更するためにクリックまたはタップできる**ドロップダウン**

Slingshot はデータを自動的に分析し、各 CSV 列を最も一致するタスク フィールドにマッピングします。たとえば、日付値を含む「期日」という名前の列は自動的に**期日**フィールドにマッピングされます。

#### Slingshot が自動的に検出するもの

| データ パターン | 検出されたフィールドの種類 |
|---|---|
| "true" / "false" 値 | **チェックボックス** |
| 日付値 | **日付** |
| 0 から 5 の数値 | **評価** |
| 0 から 100 の数値 | **手動進捗** |
| その他の数値 | **数値** |
| 長いテキスト (255 文字以上) | **長いテキスト** |
| 繰り返し値を持つ短いテキスト | **ドロップダウン** |
| それ以外のすべて | **テキスト** |

列が既存のフィールドと一致しない場合、Slingshot はデータに基づいて新しいカスタム フィールドを作成することを提案します。提案されたフィールドは、インポートを確定したときにのみタスク リストに追加されます。準備ができるまで何も変更されません。

> [!IMPORTANT]
> **Slingshot のヒント**: 列にデータがない場合、Slingshot はデフォルトで**テキスト**に設定しますが、列ヘッダーのドロップダウンを使用して、サポートされている任意のフィールドの種類に手動で変更できます。

#### 列マッピングの調整

列のマッピングは、ヘッダーをクリックまたはタップしてドロップダウンから別のフィールドを選択することで変更できます。オプションには次のものがあります:

- **既存のタスク フィールド** — _タイトル_、_ステータス_、_優先度_、_期日_、_担当者_、およびタスク リストにある任意のカスタム フィールドなど。
- **提案された新しいフィールド** — データに基づいて Slingshot が推奨するカスタム フィールド。
- **無視** — インポート中にこの列を完全にスキップします。無視された列はグリッドで淡色表示されます。

#### タスクの種類の選択

マッピング グリッドの上部には**タスクの種類セレクター**があります。ワークスペースで複数のタスクの種類を使用している場合は、切り替えてマッピングに使用できるフィールドを変更できます。

> [!IMPORTANT]
> タスクの種類を変更すると、すべての列マッピングがリセットされます。CSV データは保持されます — フィールドの割り当てのみがクリアされ、新しいタスクの種類のフィールドに再マッピングできます。

### 手順 4: 不一致を解決する

列が**ドロップダウン**または**ラベル** フィールドにマッピングされており、CSV の値の一部が既存のオプションと一致しない場合、その列ヘッダーに**警告アイコン**が表示されます。

警告アイコンをクリックまたはタップして**値マッピング** ダイアログを開きます。ここで次のことができます:

- 認識されていない値を既存のドロップダウンまたはラベル オプションに**マッピング**する
- **新しいオプションを追加** — カラー ピッカーを使用してダイアログから直接カスタム カラーで新しいアイテムを作成する

ここで作成した新しいオプションは、インポートを確定したときにのみ保存されます。キャンセルした場合、既存のフィールドは変更されません。

### 手順 5: 確定してインポートする

マッピングに満足したら、**[マッピングの適用]** をクリックまたはタップしてインポートを開始します。

> [!NOTE]
> **[マッピングの適用]** ボタンは、少なくとも 1 つの列が**タイトル** フィールドにマッピングされるまで無効になっています。すべてのタスクにタイトルが必要であり、タイトル列はすべての行に値が必要です — 空白のセルを持つ列はタイトルに使用できません。

未解決のドロップダウンまたはラベルの不一致がある場合、Slingshot は処理を続行する前に値マッピング ダイアログを 1 つずつ案内します。

## インポートの進捗の追跡

インポートを確定すると、**進捗ダイアログ**がインポートのステータスをリアルタイムで表示します。待つ必要はありません — このダイアログを閉じて Slingshot での作業を続けてください。画面の右下隅に小さな**フローティング進捗インジケーター**が表示されます。

インポートが完了すると:

- **すべてのタスクが正常にインポートされた** — 作成されたタスクの合計数と、タスク リストに直接移動するための **[そこに移動]** ボタンを含む概要が表示されます。
- **一部のタスクにエラーがあった** — 概要には成功したタスクの数と、インポートできなかった行の詳細が表示されます。

> [!NOTE]
> 一度に実行できるインポートは 1 つだけです。すでに進行中のインポートがある間に新しいインポートを開始しようとすると、Slingshot が通知します。

## インポート中のサブタスクの作成

CSV に**親タスク タイトル**列を含めることで、タスク間の親子関係を設定できます。

インポート中にサブタスクを作成するには:

1. CSV 列の 1 つを**親タスク タイトル** フィールドの種類にマッピングします。
2. 各行に、この列に親タスクの**正確なタイトル**を入力します。
3. 親タスクが CSV ファイルの子タスクの**上に**表示されていることを確認します。
4. トップレベルのタスクの**親タスク タイトル**列は空白のままにします。

> [!NOTE]
> サブタスクのネストは 1 レベルのみサポートされています — サブタスク自体が別のサブタスクの親になることはできません。

**CSV の例:**

| タイトル | ステータス | 親タスク タイトル |
|---|---|---|
| ホームページのデザイン | 進行中 | |
| ワイヤーフレームの作成 | 未着手 | ホームページのデザイン |
| カラー パレットの選択 | 未着手 | ホームページのデザイン |
| API の構築 | 未着手 | |

この例では、「ワイヤーフレームの作成」と「カラー パレットの選択」が「ホームページのデザイン」のサブタスクになり、「API の構築」はトップレベルのタスクのままです。

## サポートされているフィールド

次のタスク フィールドを CSV インポートで設定できます:

| フィールド | 注意事項 |
|---|---|
| **タイトル** | **必須。** すべての行に値が必要です。タイトルにマッピングされる列は正確に 1 つでなければなりません。 |
| **ステータス** | オプション。ステータスにマッピングされた列がない場合、タスクはデフォルトで**未着手**になります。 |
| **説明** | オプション。 |
| **優先度** | オプション。 |
| **期日** | オプション。 |
| **開始日** | オプション。 |
| **担当者** | オプション。1 つのセル内でカンマで区切られた複数の担当者をサポートします。名前またはメールはワークスペース メンバーと照合されます。 |
| **ラベル** | オプション。 |
| **カスタム フィールド** | _テキスト_、_数値_、_日付_、_チェックボックス_、_評価_、_ドロップダウン_、_長いテキスト_、_手動進捗_、_メール_、_電話番号_、および_ユーザー_フィールドがすべてサポートされています。これらはタスク リストにそれらの種類のカスタム フィールドを作成した場合にのみ適用されます。 |
| **親タスク タイトル** | オプション。親子関係を確立します (上記参照)。 |

> [!NOTE]
> _添付ファイル_、_時間追跡_、_繰り返し_、_作成日_、_完了日_など、一部のフィールドは CSV インポートでは設定できません。

## スムーズなインポートのためのヒント

- **CSV を準備する** — 最初の行に明確な列ヘッダーが含まれていることを確認します。Slingshot はこれらを使用してフィールド マッピングを自動検出します。
- **タイトルを埋める** — _タイトル_列には空白のセルを含めることができません。インポート前に空白を埋めてください。
- **一貫したドロップダウン値を使用する** — 既存のドロップダウン フィールドにインポートする場合は、CSV のオプション名を一致させて追加のマッピング手順を避けてください。
- **日付形式を確認する** — 標準的な日付形式は自動的に認識されます。
- **複数の値にカンマを使用する** — _担当者_や_ユーザー_、_メール_などの複数値カスタム フィールドについては、カンマで区切ることで 1 つのセルに複数の値を含めることができます (例: "alice@example.com, bob@example.com")。
- **日付範囲を分割する** — 日付範囲は単一のフィールドとしてサポートされていません。代わりに、別々の_開始日_と_終了日_の列を使用してください。

## 他のツールからのインポート

別のプロジェクト管理ツールにタスクがありますか? CSV としてエクスポートして Slingshot に取り込むことができます。以下は最も一般的なツールのステップ バイ ステップ ガイドです。

### ClickUp からのインポート

ClickUp ではタスクを CSV にエクスポートできます。Slingshot 用にエクスポートを準備するには:

1. **ClickUp からエクスポート** — ClickUp でタスクを CSV にエクスポートします。プロンプトが表示されたら、インポート時に日付が正しく認識されるように日付の **ISO 形式**を選択します。
2. **サブタスクを準備する** — ClickUp は各親タスクのサブタスク ID のリストとしてサブタスクの関係をエクスポートしますが、Slingshot はこれを直接読み取りません。Slingshot が理解できる形式に変換するには:
   - エクスポートされた CSV を Excel または Google スプレッドシートで開きます。
   - **親タスク タイトル**という新しい列を追加します。
   - 新しい列の最初のデータ行に次の数式を入力します (その後すべての行にコピーします):
     ```
     =IFERROR(INDEX($C:$C, MATCH("*"&TRIM(CLEAN(B2))&"*", $F:$F, 0)), "")
     ```
     列の文字をファイルに合わせて調整します:
     - **B** = _タスク ID_ 列
     - **C** = _タスク名_ 列
     - **F** = _サブタスク ID_ 列
   - ファイルを CSV として保存します。
3. **Slingshot にインポート** — 上記の標準インポート手順に従います。マッピング グリッドを確認する際に、**親タスク タイトル**列が**親タスク タイトル** フィールドの種類にマッピングされていることを確認します。

### Asana からのインポート

Asana のエクスポートにはサブタスクの関係が自動的に含まれているため、プロセスは簡単です:

1. **Asana からエクスポート** — Asana でプロジェクトを CSV にエクスポートします。サブタスクは各サブタスクの親の名前を含む**親タスク**列と共に自動的にエクスポートされます。
2. **Slingshot にインポート** — 上記の標準インポート手順に従います。マッピング グリッドを確認する際に、**親タスク**列を**親タスク タイトル** フィールドの種類にマッピングします。Slingshot は自動的に親子関係を作成します。
