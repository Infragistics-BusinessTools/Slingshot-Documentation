# CSV ファイルからタスクをインポートする

CSV タスク インポートを使用すると、スプレッドシート、他のプロジェクト管理ツール、または CSV にエクスポートできるあらゆるソースからタスクを Slingshot のタスク リストに直接移動できます。Slingshot は列の種類を自動的に検出してタスク フィールドにマッピングするため、セットアップにかける時間を減らして作業に集中できます。

> [!NOTE]
> CSV インポートは**ワークスペース オーナー**のみが利用できます。**[インポート]** オプションが表示されない場合は、ワークスペース オーナーに確認してください。

## タスクのインポート方法

### ステップ 1: インポートを開始する

CSV インポートを開始するには 2 つの方法があります:

- **タスク リストから** — タスク リストのオーバーフロー メニューをクリック/タップし、**[インポート]** を選択します。タスクが追加される「インポート」という新しいセクションが作成されます。
- **セクションから** — 特定のセクションのオーバーフロー メニューをクリック/タップし、**[インポート]** を選択します。タスクはそのセクションに直接追加されます。

> [!NOTE]
> タスク リスト メニューから複数回インポートすると、インポートごとに番号が増えた名前 (「インポート」、「インポート 2」、「インポート 3」など) の新しいセクションが作成されます。

### ステップ 2: ファイルをアップロードする

**[インポート]** を選択すると、ファイル ピッカーが開きます。`.csv` ファイルを選択すると、Slingshot が自動的に解析します。

CSV ファイルは以下のガイドラインに従ってください:

- **1 行目**には列ヘッダー (フィールド名) が含まれている必要があります。
- 以降の各行はタスクを表します。
- ファイルは最大 **50 列**、**2,000 行**まで対応しています。

### ステップ 3: マッピング グリッドを確認する

ファイルがアップロードされると、Slingshot は CSV データを列ごとに整理した**マッピング グリッド**を表示します。各列ヘッダーには以下が表示されます:

- ファイルの **CSV 列名**
- 検出されたフィールド タイプを表す**アイコン**
- フィールドのマッピングを変更するためにクリック/タップできる**ドロップダウン**

Slingshot はデータを自動的に分析し、各 CSV 列を最も一致するタスク フィールドにマッピングします。たとえば、日付値を含む「Due Date」という列は、自動的に **[期日]** フィールドにマッピングされます。

#### Slingshot が自動的に検出するもの

| データ パターン | 検出されるフィールド タイプ |
|---|---|
| "true" / "false" 値 | **チェックボックス** |
| 日付値 | **日付** |
| 0 〜 5 の数値 | **評価** |
| 0 〜 100 の数値 | **手動進捗** |
| その他の数値 | **数値** |
| 長いテキスト (255 文字超) | **長いテキスト** |
| 繰り返し値のある短いテキスト | **ドロップダウン** |
| その他すべて | **テキスト** |

列が既存のフィールドに一致しない場合、Slingshot はデータに基づいて新しいカスタム フィールドの作成を提案します。提案されたフィールドは、インポートを確認したときにのみタスク リストに追加されます — 準備ができるまで何も変更されません。

> [!IMPORTANT]
> **Slingshot ヒント**: 列にデータがない場合、Slingshot はデフォルトで**テキスト**に設定しますが、列ヘッダーのドロップダウンを使用して、サポートされている任意のフィールド タイプに手動で変更できます。

#### 列マッピングを調整する

列ヘッダーをクリック/タップしてドロップダウンから別のフィールドを選択することで、任意の列のマッピングを変更できます。オプションには以下が含まれます:

- **既存のタスク フィールド** — _タイトル_、_ステータス_、_優先度_、_期日_、_担当者_、タスク リストの既存のカスタム フィールドなど。
- **提案された新しいフィールド** — データに基づいて Slingshot が推奨するカスタム フィールド。
- **無視** — インポート中にこの列を完全にスキップします。無視された列はグリッド内でグレー表示されます。

#### タスク タイプを選択する

マッピング グリッドには上部に**タスク タイプ セレクター**が含まれています。ワークスペースで複数のタスク タイプを使用している場合、それらを切り替えてマッピングで使用できるフィールドを変更できます。

> [!IMPORTANT]
> タスク タイプを変更すると、すべての列マッピングがリセットされます。CSV データは保持されます — フィールドの割り当てのみがクリアされるため、新しいタスク タイプのフィールドに再マッピングできます。

### ステップ 4: 不一致を解決する

列が**ドロップダウン**または**ラベル** フィールドにマッピングされていて、一部の CSV 値が既存のオプションと一致しない場合、その列ヘッダーに**警告アイコン**が表示されます。

警告アイコンをクリック/タップして**値マッピング** ダイアログを開き、以下のことができます:

- 認識されない値を既存のドロップダウンまたはラベル オプションに**マッピングする**
- **新しいオプションを追加する** — ダイアログのカラー ピッカーを使用してカスタム カラーで新しいアイテムを直接作成する

ここで作成した新しいオプションは、インポートを確認したときにのみ保存されます。キャンセルした場合、既存のフィールドには何も変更されません。

### ステップ 5: 確認してインポートする

マッピングに問題がなければ、**[マッピングを適用]** をクリック/タップしてインポートを開始します。

> [!NOTE]
> **[マッピングを適用]** ボタンは、少なくとも 1 つの列が **[タイトル]** フィールドにマッピングされるまで無効です。すべてのタスクにタイトルが必要であり、タイトル列はすべての行に値が必要です — 空のセルを含む列はタイトルとして使用できません。

未解決のドロップダウンまたはラベルの不一致がある場合、Slingshot は続行前に値マッピング ダイアログを 1 つずつ案内します。

## インポートの進捗状況を追跡する

インポートを確認すると、**進捗ダイアログ**にインポートのステータスがリアルタイムで表示されます。待つ必要はありません — このダイアログを閉じて Slingshot での作業を続けられます。画面の右下隅に小さな**フローティング進捗インジケーター**が表示され、状況を確認できます。

インポートが完了すると:

- **すべてのタスクが正常にインポートされた場合** — 作成されたタスクの総数と、タスク リストに直接移動するための **[そこへ移動]** ボタンを含む概要が表示されます。
- **一部のタスクにエラーがあった場合** — 概要には成功したタスクの数と、インポートできなかった行の詳細が表示されます。

> [!NOTE]
> 一度に実行できるインポートは 1 つのみです。インポートが進行中に新しいインポートを開始しようとすると、Slingshot は通知します。

## インポート中にサブタスクを作成する

CSV に**親タスクのタイトル**列を含めることで、タスク間の親子関係を設定できます。

インポート中にサブタスクを作成するには:

1. CSV 列の 1 つを**親タスクのタイトル** フィールド タイプにマッピングします。
2. 各行に、この列に親タスクの**正確なタイトル**を入力します。
3. 親タスクが CSV ファイル内で子タスクの**上に**表示されるようにします。
4. トップレベルのタスクの**親タスクのタイトル**列は空のままにします。

> [!NOTE]
> サポートされるサブタスクのネストは 1 レベルのみです — サブタスク自体が別のサブタスクの親になることはできません。

**CSV の例:**

| タイトル | ステータス | 親タスクのタイトル |
|---|---|---|
| ホームページのデザイン | 進行中 | |
| ワイヤーフレームの作成 | 予定 | ホームページのデザイン |
| カラー パレットの選択 | 予定 | ホームページのデザイン |
| API の構築 | 予定 | |

この例では、「ワイヤーフレームの作成」と「カラー パレットの選択」は「ホームページのデザイン」のサブタスクになり、「API の構築」はトップレベルのタスクのままです。

## サポートされているフィールド

CSV インポートを通じて入力できるタスク フィールドは以下のとおりです:

| フィールド | 注記 |
|---|---|
| **タイトル** | **必須。** すべての行に値が必要です。タイトルにマッピングできる列は 1 つのみです。 |
| **ステータス** | 省略可能。ステータスにマッピングされた列がない場合、タスクはデフォルトで **[予定]** になります。 |
| **説明** | 省略可能。 |
| **優先度** | 省略可能。 |
| **期日** | 省略可能。 |
| **開始日** | 省略可能。 |
| **担当者** | 省略可能。1 つのセル内でコンマで区切ることで複数の担当者をサポートします。名前またはメールはワークスペース メンバーと照合されます。 |
| **ラベル** | 省略可能。 |
| **カスタム フィールド** | _テキスト_、_数値_、_日付_、_チェックボックス_、_評価_、_ドロップダウン_、_長いテキスト_、_手動進捗_、_メール_、_電話番号_、_ピープル_ フィールドはすべてサポートされています。これらは、タスク リストにそれらのタイプのカスタム フィールドを作成済みの場合にのみ適用されます。 |
| **親タスクのタイトル** | 省略可能。親子関係を確立します (上記参照)。 |

> [!NOTE]
> _添付ファイル_、_時間追跡_、_繰り返し_、_作成日_、_完了日_ などの一部のフィールドは CSV インポートを通じて入力できません。

## スムーズなインポートのためのヒント

- **CSV を準備する** — 1 行目に明確な列ヘッダーが含まれていることを確認してください。Slingshot はこれらを使用してフィールド マッピングを自動検出します。
- **タイトルを入力しておく** — _タイトル_ 列に空のセルを含めることはできません。インポート前にすべての空白を埋めてください。
- **一貫したドロップダウン値を使用する** — 既存のドロップダウン フィールドにインポートする場合、追加のマッピング手順を避けるために CSV のオプション名を一致させてください。
- **日付形式を確認する** — 標準的な日付形式は自動的に認識されます。
- **複数の値にはコンマを使用する** — _担当者_ や _ピープル_、_メール_ などの複数値カスタム フィールドには、コンマで区切ることで 1 つのセルに複数の値を含めることができます (例: "alice@example.com, bob@example.com")。
- **日付範囲を分割する** — 日付範囲は単一フィールドとしてサポートされていません。代わりに個別の _開始日_ および _終了日_ 列を使用してください。

## 他のツールからインポートする

別のプロジェクト管理ツールにタスクがある場合は、CSV としてエクスポートして Slingshot にインポートできます。以下は、最も一般的なツールのステップ バイ ステップ ガイドです。

### ClickUp からインポートする

ClickUp ではタスクを CSV にエクスポートできます。Slingshot 用にエクスポートを準備するには:

1. **ClickUp からエクスポートする** — ClickUp でタスクを CSV にエクスポートします。プロンプトが表示されたら、インポート中に日付が正しく認識されるように、日付に **ISO 形式**を選択します。
2. **サブタスクを準備する** — ClickUp は各親タスクのサブタスク ID リストとしてサブタスクの関係をエクスポートしますが、Slingshot はこれを直接読み取ることができません。Slingshot が理解できる形式に変換するには:
   - Excel または Google スプレッドシートでエクスポートした CSV を開きます。
   - **親タスクのタイトル**という新しい列を追加します。
   - 新しい列の最初のデータ行に次の数式を入力します (すべての行にコピーします):
     ```
     =IFERROR(INDEX($C:$C, MATCH("*"&TRIM(CLEAN(B2))&"*", $F:$F, 0)), "")
     ```
     ファイルに合わせて列文字を調整します:
     - **B** = _タスク ID_ 列
     - **C** = _タスク名_ 列
     - **F** = _サブタスク ID_ 列
   - ファイルを CSV として保存します。
3. **Slingshot にインポートする** — 上記の標準インポート手順に従ってください。マッピング グリッドを確認するとき、**親タスクのタイトル**列を**親タスクのタイトル** フィールド タイプにマッピングしてください。

### Asana からインポートする

Asana のエクスポートにはサブタスクの関係が含まれており、プロセスは簡単です:

1. **Asana からエクスポートする** — Asana でプロジェクトを CSV にエクスポートします。サブタスクは、各サブタスクの親の名前を含む**親タスク**列と共に自動的にエクスポートされます。
2. **Slingshot にインポートする** — 上記の標準インポート手順に従ってください。マッピング グリッドを確認するとき、**親タスク**列を**親タスクのタイトル** フィールド タイプにマッピングします。Slingshot は自動的に親子関係を作成します。
