# CSV ファイルからタスクをインポートする

CSV タスク インポートを使用すると、スプレッドシート、他のプロジェクト管理ツール、または CSV にエクスポートできる任意のソースから Slingshot のタスク リストに直接タスクをすばやく移動できます。Slingshot は列のタイプを自動的に検出してタスク フィールドにマッピングするため、セットアップの時間を短縮して作業に集中できます。

> [!NOTE]
>CSV インポートは**ワークスペース オーナー**のみが利用できます。**[インポート]** オプションが表示されない場合は、ワークスペース オーナーに確認してください。

## タスクのインポート方法

### ステップ 1: インポートを開始する

CSV インポートを開始する方法は 2 つあります:

- **タスク リストから** — タスク リストのオーバーフロー メニューをクリック/タップして **[インポート]** を選択します。「インポート」という新しいセクションが作成され、タスクがそこに追加されます。
- **セクションから** — 特定のセクションのオーバーフロー メニューをクリック/タップして **[インポート]** を選択します。タスクはそのセクションに直接追加されます。

> [!NOTE]
>タスク リスト メニューから複数回インポートすると、各インポートで連番の名前を持つ新しいセクションが作成されます（例：「インポート」、「インポート 2」、「インポート 3」）。

### ステップ 2: ファイルをアップロードする

**[インポート]** を選択すると、ファイル ピッカーが開きます。`.csv` ファイルを選択すると、Slingshot が自動的に解析します。

CSV ファイルは以下のガイドラインに従ってください:

- **1 行目**には列ヘッダー（フィールド名）が必要です。
- 2 行目以降の各行がタスクを表します。
- ファイルは最大 **50 列**、**2,000 行**まで対応しています。

### ステップ 3: マッピング グリッドを確認する

ファイルをアップロードすると、Slingshot は CSV データを列ごとに整理した**マッピング グリッド**を表示します。各列ヘッダーには以下が表示されます:

- ファイルの **CSV 列名**
- 検出されたフィールド タイプを表す**アイコン**
- フィールド マッピングを変更するためにクリック/タップできる**ドロップダウン**

Slingshot はデータを自動的に分析し、各 CSV 列を最も適合するタスク フィールドにマッピングします。たとえば、日付値を含む「期日」という名前の列は、自動的に**期日**フィールドにマッピングされます。

#### Slingshot が自動的に検出するもの

| データ パターン | 検出されたフィールド タイプ |
|---|---|
| "true" / "false" の値 | **チェックボックス** |
| 日付の値 | **日付** |
| 0 から 5 の数値 | **評価** |
| 0 から 100 の数値 | **手動進捗** |
| その他の数値 | **数値** |
| 長いテキスト（255 文字以上） | **長いテキスト** |
| 繰り返し値を持つ短いテキスト | **ドロップダウン** |
| その他すべて | **テキスト** |

列がタスク リストの既存フィールドと一致しない場合、Slingshot はデータに基づいて新しいカスタム フィールドの作成を提案します。提案されたフィールドはインポートを確定したときのみタスク リストに追加されます — 準備ができるまで何も変更されません。

> [!IMPORTANT]
>**Slingshot ヒント**: 列にデータがない場合、Slingshot はデフォルトで**テキスト**に設定しますが、列ヘッダーのドロップダウンを使用して任意のサポートされているフィールド タイプに手動で変更できます。

#### 列マッピングの調整

列のヘッダーをクリック/タップしてドロップダウンから別のフィールドを選択することで、任意の列のマッピングを変更できます。オプションには以下が含まれます:

- **既存のタスク フィールド** — _タイトル_、_ステータス_、_優先度_、_期日_、_担当者_、タスク リストにすでにあるカスタム フィールドなど。
- **提案された新しいフィールド** — データに基づいて Slingshot が推奨するカスタム フィールド。
- **無視** — インポート時にこの列を完全にスキップします。無視された列はグリッドに淡色表示されます。

#### タスク タイプの選択

マッピング グリッドの上部には**タスク タイプ セレクター**があります。ワークスペースが複数のタスク タイプを使用している場合は、切り替えてマッピングに使用できるフィールドを変更できます。

> [!IMPORTANT]
>タスク タイプを変更すると、すべての列マッピングがリセットされます。CSV データは保持されます — 新しいタスク タイプのフィールドに再マッピングできるよう、フィールドの割り当てのみがクリアされます。

### ステップ 4: 不一致を解消する

列が**ドロップダウン**または**ラベル** フィールドにマッピングされており、CSV の一部の値が既存のオプションと一致しない場合、その列ヘッダーに**警告アイコン**が表示されます。

警告アイコンをクリック/タップして**値マッピング** ダイアログを開き、以下を行えます:

- 認識されない値を既存のドロップダウンまたはラベルのオプションに**マッピング**する
- **新しいオプションを追加する** — ダイアログのカラー ピッカーからカスタム カラーで新しい項目を直接作成する

ここで作成した新しいオプションは、インポートを確定したときのみ保存されます。キャンセルした場合、既存のフィールドは変更されません。

### ステップ 5: 確定してインポートする

マッピングに問題がなければ、**[マッピングを適用]** をクリック/タップしてインポートを開始します。

> [!NOTE]
>少なくとも 1 つの列が**タイトル** フィールドにマッピングされるまで、**[マッピングを適用]** ボタンは無効のままです。すべてのタスクにタイトルが必要であり、タイトル列はすべての行に値が必要です — 空白のセルがある列はタイトルには使用できません。

未解消のドロップダウンまたはラベルの不一致がある場合、Slingshot は続行する前に値マッピング ダイアログを 1 つずつガイドします。

## インポートの進捗を追跡する

インポートを確定すると、**進捗ダイアログ**にリアルタイムでインポートのステータスが表示されます。待つ必要はありません — このダイアログを閉じて Slingshot での作業を続けることができます。画面の右下隅に小さな**フローティング進捗インジケーター**が表示され、状況を確認できます。

インポートが完了すると:

- **すべてのタスクが正常にインポートされた場合** — 作成されたタスクの合計数と、タスク リストに直接移動する **[そこへ移動]** ボタンを含む概要が表示されます。
- **一部のタスクにエラーがあった場合** — 成功したタスク数とインポートできなかった行の詳細が表示されます。

> [!NOTE]
>一度に実行できるインポートは 1 つだけです。インポートが進行中に新しいインポートを開始しようとすると、Slingshot がお知らせします。

## インポート時にサブタスクを作成する

CSV に**親タスク タイトル**列を含めることで、タスク間の親子関係を設定できます。

インポート時にサブタスクを作成するには:

1. CSV の列の 1 つを**親タスク タイトル** フィールド タイプにマッピングします。
2. 各行に、この列に親タスクの**正確なタイトル**を入力します。
3. CSV ファイルで親タスクが子タスクの**上**に表示されることを確認します。
4. トップ レベルのタスクの**親タスク タイトル**列は空のままにします。

> [!NOTE]
>サポートされるサブタスクのネストは 1 レベルのみです — サブタスク自体が別のサブタスクの親になることはできません。

**CSV の例:**

| タイトル | ステータス | 親タスク タイトル |
|---|---|---|
| ホームページのデザイン | 進行中 | |
| ワイヤーフレームの作成 | 未着手 | ホームページのデザイン |
| カラーパレットの選択 | 未着手 | ホームページのデザイン |
| API の構築 | 未着手 | |

この例では、「ワイヤーフレームの作成」と「カラーパレットの選択」が「ホームページのデザイン」のサブタスクになり、「API の構築」はトップ レベルのタスクのままです。

## サポートされているフィールド

CSV インポートで入力できるタスク フィールドは以下のとおりです:

| フィールド | 備考 |
|---|---|
| **タイトル** | **必須。** すべての行に値が必要です。タイトルにマッピングできる列は 1 つだけです。 |
| **ステータス** | 省略可。ステータスにマッピングされた列がない場合、タスクはデフォルトで**未着手**になります。 |
| **説明** | 省略可。 |
| **優先度** | 省略可。 |
| **期日** | 省略可。 |
| **開始日** | 省略可。 |
| **担当者** | 省略可。セル内でカンマ区切りで複数の担当者をサポートします。名前またはメールアドレスがワークスペース メンバーと照合されます。 |
| **ラベル** | 省略可。 |
| **カスタム フィールド** | _テキスト_、_数値_、_日付_、_チェックボックス_、_評価_、_ドロップダウン_、_長いテキスト_、_手動進捗_、_メール_、_電話番号_、_ユーザー_ フィールドがすべてサポートされています。これらはタスク リストにそれらのタイプのカスタム フィールドが作成されている場合にのみ適用されます。 |
| **親タスク タイトル** | 省略可。親子関係を確立します（上記を参照）。 |

> [!NOTE]
>_添付ファイル_、_時間追跡_、_繰り返し_、_作成日_、_完了日_など、一部のフィールドは CSV インポートでは入力できません。

## スムーズなインポートのためのヒント

- **CSV を準備する** — 1 行目に明確な列ヘッダーがあることを確認します。Slingshot はこれを使用してフィールド マッピングを自動検出します。
- **タイトルを入力する** — _タイトル_列に空白のセルがあってはなりません。インポート前にギャップを埋めてください。
- **一貫したドロップダウン値を使用する** — 既存のドロップダウン フィールドにインポートする場合は、余分なマッピング手順を避けるために CSV のオプション名を一致させます。
- **日付形式を確認する** — 標準的な日付形式は自動的に認識されます。
- **複数の値にはカンマを使用する** — _担当者_や_ユーザー_、_メール_などの複数値カスタム フィールドには、カンマ区切りで 1 つのセルに複数の値を含めることができます（例：「alice@example.com, bob@example.com」）。
- **日付範囲を分割する** — 日付範囲は単一フィールドとしてはサポートされていません。代わりに個別の_開始日_と_終了日_列を使用してください。

## 他のツールからのインポート

別のプロジェクト管理ツールにタスクが既にありますか？CSV としてエクスポートして Slingshot に取り込むことができます。以下に、最も一般的なツールのステップバイステップ ガイドを示します。

### ClickUp からのインポート

ClickUp ではタスクを CSV にエクスポートできます。Slingshot 用にエクスポートを準備するには:

1. **ClickUp からエクスポート** — ClickUp でタスクを CSV にエクスポートします。プロンプトが表示されたら、インポート時に日付が正しく認識されるように日付には **ISO フォーマット**を選択します。
2. **サブタスクを準備する** — ClickUp は各親タスクのサブタスク ID リストとしてサブタスク関係をエクスポートします。Slingshot はこれを直接読み取れません。Slingshot が理解できる形式に変換するには:
   - エクスポートされた CSV を Excel または Google スプレッドシートで開きます。
   - **親タスク タイトル**という新しい列を追加します。
   - 新しい列の最初のデータ行に次の数式を入力し（すべての行にコピー）:
     ```
     =IFERROR(INDEX($C:$C, MATCH("*"&TRIM(CLEAN(B2))&"*", $F:$F, 0)), "")
     ```
     列の文字をファイルに合わせて調整します:
     - **B** = _タスク ID_ 列
     - **C** = _タスク名_ 列
     - **F** = _サブタスク ID_ 列
   - ファイルを CSV として保存します。
3. **Slingshot にインポート** — 上記の標準的なインポート手順に従います。マッピング グリッドを確認する際は、**親タスク タイトル**列が**親タスク タイトル** フィールド タイプにマッピングされていることを確認します。

### Asana からのインポート

Asana のエクスポートにはサブタスク関係が最初から含まれているため、手順は簡単です:

1. **Asana からエクスポート** — Asana でプロジェクトを CSV にエクスポートします。サブタスクは各サブタスクの親の名前を含む**親タスク**列とともに自動的にエクスポートされます。
2. **Slingshot にインポート** — 上記の標準的なインポート手順に従います。マッピング グリッドを確認する際は、**親タスク**列を**親タスク タイトル** フィールド タイプにマッピングします。Slingshot が自動的に親子関係を作成します。
