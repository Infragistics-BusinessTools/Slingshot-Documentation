# CSV ファイルからのタスクのインポート

CSV タスク インポートを使用すると、スプレッドシート、他のプロジェクト管理ツール、または CSV にエクスポートできるソースからタスクを Slingshot のタスク リストに直接移動できます。Slingshot は列タイプを自動的に検出してタスク フィールドにマッピングするため、セットアップの時間を節約して作業に集中できます。

> [!NOTE]
>CSV インポートは**ワークスペース オーナー**のみが使用できます。**[インポート]** オプションが表示されない場合は、ワークスペース オーナーに確認してください。

## タスクのインポート方法

### ステップ 1: インポートを開始する

CSV インポートを開始するには 2 つの方法があります。

- **タスク リストから** — タスク リストのオーバーフロー メニューをクリック/タップして **[インポート]** を選択します。タスクが追加される "インポート" という新しいセクションが作成されます。
- **セクションから** — 特定のセクションのオーバーフロー メニューをクリック/タップして **[インポート]** を選択します。タスクはそのセクションに直接追加されます。

> [!NOTE]
>タスク リスト メニューから複数回インポートすると、各インポートごとに番号が増加した名前 ("インポート"、"インポート 2"、"インポート 3" など) の新しいセクションが作成されます。

### ステップ 2: ファイルをアップロードする

**[インポート]** を選択すると、ファイル選択ダイアログが開きます。`.csv` ファイルを選択すると、Slingshot が自動的に解析します。

CSV ファイルは以下のガイドラインに従ってください。

- **最初の行**には列ヘッダー (フィールド名) を含める必要があります。
- 以降の各行はタスクを表します。
- ファイルは最大 **50 列** および **2,000 行** まで使用できます。

### ステップ 3: マッピング グリッドを確認する

ファイルがアップロードされると、Slingshot は CSV データを列ごとに整理した**マッピング グリッド**を表示します。各列ヘッダーには以下が表示されます。

- ファイルの **CSV 列名**
- 検出されたフィールド タイプを表す**アイコン**
- フィールド マッピングを変更するためにクリック/タップできる**ドロップダウン**

Slingshot はデータを自動的に分析し、各 CSV 列を最も適切なタスク フィールドにマッピングします。たとえば、日付値を含む "期日" という名前の列は、自動的に**期日**フィールドにマッピングされます。

#### Slingshot が自動的に検出するもの

| データ パターン | 検出されたフィールド タイプ |
|---|---|
| "true" / "false" の値 | **チェックボックス** |
| 日付値 | **日付** |
| 0 から 5 の数値 | **評価** |
| 0 から 100 の数値 | **手動進捗** |
| その他の数値 | **数値** |
| 長いテキスト (255 文字以上) | **長いテキスト** |
| 繰り返し値を持つ短いテキスト | **ドロップダウン** |
| その他すべて | **テキスト** |

列にデータがない場合、Slingshot はデフォルトで**テキスト**にしますが、列ヘッダーのドロップダウンを使用して任意のサポートされているフィールド タイプに手動で変更できます。

> [!IMPORTANT]
>**Slingshot ヒント**: 列にデータがない場合、Slingshot はデフォルトで**テキスト**にしますが、列ヘッダーのドロップダウンを使用して任意のサポートされているフィールド タイプに手動で変更できます。

#### 列マッピングの調整

任意の列のマッピングを変更するには、ヘッダーをクリック/タップしてドロップダウンから別のフィールドを選択します。オプションには以下が含まれます。

- **既存のタスク フィールド** — _タイトル_、_ステータス_、_優先度_、_期日_、_担当者_、タスク リスト内の任意のカスタム フィールドなど。
- **新しいフィールドの提案** — データに基づいて Slingshot が推奨するカスタム フィールド。
- **無視** — インポート中にこの列をスキップします。無視された列はグリッドでグレー表示されます。

#### タスク タイプの選択

マッピング グリッドには上部に**タスク タイプ セレクター**があります。ワークスペースで複数のタスク タイプを使用している場合、それらを切り替えてマッピングに使用できるフィールドを変更できます。

> [!IMPORTANT]
>タスク タイプを変更すると、すべての列マッピングがリセットされます。CSV データは保持されますが、新しいタスク タイプのフィールドに再マッピングできるようにフィールドの割り当てのみがクリアされます。

### ステップ 4: 不一致を解決する

列が**ドロップダウン**または**ラベル** フィールドにマッピングされていて、CSV の値が既存のオプションと一致しない場合、その列ヘッダーに**警告アイコン**が表示されます。

警告アイコンをクリック/タップして**値マッピング** ダイアログを開き、以下の操作ができます。

- 認識されない値を既存のドロップダウンまたはラベル オプションに**マッピング**する
- **新しいオプションを追加する** — ダイアログからカラー ピッカーを使用してカスタム色で直接新しいアイテムを作成する

ここで作成した新しいオプションは、インポートを確定したときのみ保存されます。キャンセルした場合、既存のフィールドは変更されません。

### ステップ 5: 確定してインポートする

マッピングに満足したら、**[マッピングの適用]** をクリック/タップしてインポートを開始します。

> [!NOTE]
>**[マッピングの適用]** ボタンは、少なくとも 1 つの列が**タイトル** フィールドにマッピングされるまで無効です。すべてのタスクにタイトルが必要であり、タイトル列はすべての行に値が必要です。空白のセルを持つ列はタイトルに使用できません。

未解決のドロップダウンまたはラベルの不一致がある場合、Slingshot は続行する前に値マッピング ダイアログを 1 つずつ表示します。

## インポートの進捗状況の追跡

インポートを確定すると、**進捗ダイアログ**にリアルタイムでインポートの状態が表示されます。待つ必要はありません。このダイアログを閉じて Slingshot での作業を続けることができます。画面右下隅に**浮動する進捗インジケーター**が表示されるので、状況を確認できます。

インポートが完了すると:

- **すべてのタスクが正常にインポートされた場合** — 作成されたタスクの総数と、タスク リストに直接移動する **[そこに移動]** ボタンを含む概要が表示されます。
- **一部のタスクにエラーがあった場合** — 成功したタスクの数と、インポートできなかった行の詳細が表示されます。

> [!NOTE]
>一度に実行できるインポートは 1 つだけです。既にインポートが進行中の状態で新しいインポートを開始しようとすると、Slingshot から通知されます。

## インポート中のサブタスクの作成

CSV に**親タスクのタイトル**列を含めることで、タスク間の親子関係を設定できます。

インポート中にサブタスクを作成するには:

1. CSV の列の 1 つを**親タスクのタイトル** フィールド タイプにマッピングします。
2. 各行に、この列に親タスクの**正確なタイトル**を入力します。
3. 親タスクが CSV ファイルで子タスクの**上**に表示されていることを確認します。
4. トップレベルのタスクの**親タスクのタイトル**列は空のままにします。

> [!NOTE]
>サポートされるサブタスクのネストは 1 レベルのみです。サブタスク自体が別のサブタスクの親になることはできません。

**CSV の例:**

| タイトル | ステータス | 親タスクのタイトル |
|---|---|---|
| ホームページのデザイン | 進行中 | |
| ワイヤーフレームの作成 | 未着手 | ホームページのデザイン |
| カラー パレットの選択 | 未着手 | ホームページのデザイン |
| API の構築 | 未着手 | |

この例では、"ワイヤーフレームの作成" と "カラー パレットの選択" は "ホームページのデザイン" のサブタスクになり、"API の構築" はトップレベルのタスクのまま残ります。

## サポートされているフィールド

CSV インポートでは以下のタスク フィールドを入力できます。

| フィールド | 注記 |
|---|---|
| **タイトル** | **必須。** すべての行に値が必要です。1 つの列だけがタイトルにマッピングされる必要があります。 |
| **ステータス** | 任意。ステータスにマッピングされた列がない場合、タスクはデフォルトで**未着手**になります。 |
| **説明** | 任意。 |
| **優先度** | 任意。 |
| **期日** | 任意。 |
| **開始日** | 任意。 |
| **担当者** | 任意。1 つのセル内にコンマで区切られた複数の担当者をサポートします。名前またはメール アドレスはワークスペース メンバーと照合されます。 |
| **ラベル** | 任意。 |
| **カスタム フィールド** | _テキスト_、_数値_、_日付_、_チェックボックス_、_評価_、_ドロップダウン_、_長いテキスト_、_手動進捗_、_メール_、_電話番号_、および _ユーザー_ フィールドがすべてサポートされています。タスク リストにそれらのタイプのカスタム フィールドを作成している場合にのみ適用されます。 |
| **親タスクのタイトル** | 任意。親子関係を設定します (上記参照)。 |

> [!NOTE]
>_添付ファイル_、_時間追跡_、_繰り返し_、_作成日_、_完了日_ など、一部のフィールドは CSV インポートで入力できません。

## スムーズなインポートのためのヒント

- **CSV を準備する** — 最初の行に明確な列ヘッダーがあることを確認してください。Slingshot はこれを使用してフィールド マッピングを自動検出します。
- **タイトルを入力しておく** — _タイトル_ 列に空白のセルを含めることはできません。インポート前にすべてのギャップを埋めてください。
- **一貫したドロップダウン値を使用する** — 既存のドロップダウン フィールドにインポートする場合は、余分なマッピング手順を避けるために CSV のオプション名を一致させてください。
- **日付形式を確認する** — 標準的な日付形式は自動的に認識されます。
- **複数の値にはコンマを使用する** — _担当者_ や _ユーザー_ や _メール_ などの複数値のカスタム フィールドには、コンマで区切ることで 1 つのセルに複数の値を含めることができます (例: "alice@example.com, bob@example.com")。
- **日付範囲を分割する** — 日付範囲は単一フィールドとしてサポートされていません。代わりに別々の _開始日_ と _終了日_ 列を使用してください。

## 他のツールからのインポート

すでに他のプロジェクト管理ツールにタスクがある場合は、CSV としてエクスポートして Slingshot に取り込むことができます。以下に最も一般的なツールのステップ バイ ステップ ガイドを示します。

### ClickUp からのインポート

ClickUp ではタスクを CSV にエクスポートできます。Slingshot 用にエクスポートを準備するには:

1. **ClickUp からエクスポートする** — ClickUp でタスクを CSV にエクスポートします。プロンプトが表示されたら、インポート中に正しく認識されるよう日付に **ISO フォーマット**を選択してください。
2. **サブタスクを準備する** — ClickUp は各親タスクのサブタスク ID リストとしてサブタスク関係をエクスポートしますが、Slingshot はこれを直接読み取れません。Slingshot が理解できる形式に変換するには:
   - エクスポートされた CSV を Excel または Google スプレッドシートで開きます。
   - **親タスクのタイトル**という新しい列を追加します。
   - 新しい列の最初のデータ行に以下の数式を入力します (すべての行にコピーしてください):
     ```
     =IFERROR(INDEX($C:$C, MATCH("*"&TRIM(CLEAN(B2))&"*", $F:$F, 0)), "")
     ```
     ファイルに合わせて列文字を調整してください:
     - **B** = _タスク ID_ 列
     - **C** = _タスク名_ 列
     - **F** = _サブタスク ID_ 列
   - ファイルを CSV として保存します。
3. **Slingshot にインポートする** — 上記の標準的なインポート手順に従ってください。マッピング グリッドを確認するときに、**親タスクのタイトル** 列が**親タスクのタイトル** フィールド タイプにマッピングされていることを確認してください。

### Asana からのインポート

Asana のエクスポートにはサブタスク関係が標準で含まれているため、プロセスは簡単です。

1. **Asana からエクスポートする** — Asana でプロジェクトを CSV にエクスポートします。サブタスクは各サブタスクの親の名前を含む**親タスク** 列と共に自動的にエクスポートされます。
2. **Slingshot にインポートする** — 上記の標準的なインポート手順に従ってください。マッピング グリッドを確認するときに、**親タスク** 列を**親タスクのタイトル** フィールド タイプにマッピングしてください。Slingshot は自動的に親子関係を作成します。
