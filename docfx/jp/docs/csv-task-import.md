# CSV ファイルからのタスクのインポート

CSV タスク インポートを使用すると、スプレッドシート、その他のプロジェクト管理ツール、または CSV にエクスポートする任意のソースからタスクを Slingshot タスク リストに直接すばやく移動できます。Slingshot は列の種類を自動的に検出してタスク フィールドにマッピングするため、設定にかける時間を減らして作業に集中できます。

> [!NOTE]
>CSV インポートは**ワークスペース オーナー**のみが利用できます。**[インポート]** オプションが表示されない場合は、ワークスペース オーナーに確認してください。

## タスクのインポート方法

### 手順 1: インポートを開始する

CSV インポートを開始する方法は 2 つあります:

- **タスク リストから** — タスク リストのオーバーフロー メニューをクリックまたはタップして **[インポート]** を選択します。タスクが追加される「インポート」という新しいセクションが作成されます。
- **セクションから** — 特定のセクションのオーバーフロー メニューをクリックまたはタップして **[インポート]** を選択します。タスクはそのセクションに直接追加されます。

> [!NOTE]
>タスク リスト メニューから複数回インポートすると、インポートのたびに番号が増分された名前で新しいセクションが作成されます (例: 「インポート」、「インポート 2」、「インポート 3」)。

### 手順 2: ファイルをアップロードする

**[インポート]** を選択すると、ファイル ピッカーが開きます。`.csv` ファイルを選択すると、Slingshot が自動的に解析します。

CSV ファイルは次のガイドラインに従う必要があります:

- **最初の行**には列ヘッダー (フィールド名) を含める必要があります。
- 後続の各行はタスクを表します。
- ファイルには最大 **50 列**と **2,000 行**を含めることができます。

### 手順 3: マッピング グリッドを確認する

ファイルをアップロードすると、Slingshot は CSV データを列ごとに整理した**マッピング グリッド**を表示します。各列ヘッダーには次の情報が表示されます:

- ファイルの **CSV 列名**
- 検出されたフィールド タイプを表す**アイコン**
- フィールド マッピングを変更するためにクリックまたはタップできる**ドロップダウン**

Slingshot はデータを自動的に分析し、各 CSV 列を最適なタスク フィールドにマッピングします。たとえば、日付値を含む「期限」という列は、自動的に**期限**フィールドにマッピングされます。

#### Slingshot が自動的に検出するもの

| データ パターン | 検出されたフィールド タイプ |
|---|---|
| 「true」/「false」の値 | **チェックボックス** |
| 日付値 | **日付** |
| 0 ～ 5 の数値 | **評価** |
| 0 ～ 100 の数値 | **手動進捗** |
| その他の数値 | **数値** |
| 長いテキスト (255 文字以上) | **長いテキスト** |
| 繰り返し値を含む短いテキスト | **ドロップダウン** |
| その他すべて | **テキスト** |

列が タスク リストの既存のフィールドと一致しない場合、Slingshot はデータに基づいて新しいカスタム フィールドの作成を提案します。提案されたフィールドは、インポートを確認した場合にのみタスク リストに追加されます。準備が完了するまで何も変更されません。

> [!IMPORTANT]
>**Slingshot ヒント**: 列にデータがない場合、Slingshot はデフォルトで**テキスト**に設定しますが、列ヘッダーのドロップダウンを使用して、任意のサポートされているフィールド タイプに手動で変更できます。

#### 列マッピングの調整

列ヘッダーをクリックまたはタップしてドロップダウンから別のフィールドを選択することで、任意の列のマッピングを変更できます。オプションには以下が含まれます:

- **既存のタスク フィールド** — _タイトル_、_ステータス_、_優先度_、_期限_、_担当者_、タスク リストに既に含まれるカスタム フィールドなど。
- **推奨される新しいフィールド** — データに基づいて Slingshot が推奨するカスタム フィールド。
- **無視** — インポート中にこの列をスキップします。無視された列はグリッドで淡色表示されます。

#### タスク タイプの選択

マッピング グリッドの上部には**タスク タイプ セレクター**があります。ワークスペースが複数のタスク タイプを使用している場合、それらを切り替えてマッピングに使用できるフィールドを変更できます。

> [!IMPORTANT]
>タスク タイプを変更すると、すべての列マッピングがリセットされます。CSV データは保持されます。フィールドの割り当てのみがクリアされるので、新しいタスク タイプのフィールドに再マッピングできます。

### 手順 4: 不一致を解決する

列が**ドロップダウン**または**ラベル** フィールドにマッピングされ、一部の CSV 値が既存のオプションと一致しない場合、その列ヘッダーに**警告アイコン**が表示されます。

警告アイコンをクリックまたはタップして**値マッピング** ダイアログを開き、次のことができます:

- 認識されない値を既存のドロップダウンまたはラベル オプションに**マッピング**する
- **新しいオプションを追加** — カラー ピッカーを使用してダイアログから直接カスタム カラーで新しいアイテムを作成する

ここで作成した新しいオプションは、インポートを確認した場合にのみ保存されます。キャンセルした場合、既存のフィールドは何も変更されません。

### 手順 5: 確認してインポートする

マッピングに満足したら、**[マッピングの適用]** をクリックまたはタップしてインポートを開始します。

> [!NOTE]
>少なくとも 1 つの列が**タイトル** フィールドにマッピングされるまで、**[マッピングの適用]** ボタンは無効になっています。すべてのタスクにタイトルが必要で、タイトル列にはすべての行に値が必要です。空白のセルを持つ列はタイトルに使用できません。

未解決のドロップダウンまたはラベルの不一致がある場合、Slingshot は続行前に値マッピング ダイアログを 1 つずつ表示します。

## インポートの進捗の追跡

インポートを確認した後、**進捗ダイアログ**がインポートのステータスをリアルタイムで表示します。待つ必要はありません。このダイアログを閉じて Slingshot での作業を続けられます。画面右下に小さな**フローティング進捗インジケーター**が表示され、進捗を確認できます。

インポートが完了すると:

- **すべてのタスクが正常にインポートされた** — 作成されたタスクの合計数と、タスク リストに直接移動するための **[そこに移動]** ボタンを含む概要が表示されます。
- **一部のタスクでエラーが発生した** — 成功したタスクの数と、インポートできなかった行の詳細が概要に表示されます。

> [!NOTE]
>一度に実行できるインポートは 1 つだけです。別のインポートが進行中の間に新しいインポートを開始しようとすると、Slingshot が通知します。

## インポート中のサブタスクの作成

CSV に**親タスク タイトル**列を含めることで、タスク間の親子関係を設定できます。

インポート中にサブタスクを作成するには:

1. CSV の列の 1 つを**親タスク タイトル** フィールド タイプにマッピングします。
2. 各行に、この列に親タスクの**正確なタイトル**を入力します。
3. CSV ファイルで親タスクが子タスクの**上に**表示されることを確認します。
4. トップレベルのタスクの**親タスク タイトル**列は空白のままにします。

> [!NOTE]
>サブタスクのネストは 1 レベルのみサポートされています。サブタスク自体が別のサブタスクの親になることはできません。

**CSV 例:**

| タイトル | ステータス | 親タスク タイトル |
|---|---|---|
| ホームページのデザイン | 進行中 | |
| ワイヤーフレームの作成 | 予定 | ホームページのデザイン |
| カラー パレットの選択 | 予定 | ホームページのデザイン |
| API の構築 | 予定 | |

この例では、「ワイヤーフレームの作成」と「カラー パレットの選択」は「ホームページのデザイン」のサブタスクになり、「API の構築」はトップレベルのタスクのままです。

## サポートされているフィールド

CSV インポートで設定できるタスク フィールドは次のとおりです:

| フィールド | 注意事項 |
|---|---|
| **タイトル** | **必須。** 各行に値が必要です。タイトルにマッピングできる列は 1 つだけです。 |
| **ステータス** | オプション。ステータスにマッピングされた列がない場合、タスクはデフォルトで**未着手**になります。 |
| **説明** | オプション。 |
| **優先度** | オプション。 |
| **期限** | オプション。 |
| **開始日** | オプション。 |
| **担当者** | オプション。1 つのセル内でカンマで区切ることで複数の担当者をサポートします。名前またはメールはワークスペース メンバーと照合されます。 |
| **ラベル** | オプション。 |
| **カスタム フィールド** | _テキスト_、_数値_、_日付_、_チェックボックス_、_評価_、_ドロップダウン_、_長いテキスト_、_手動進捗_、_メール_、_電話番号_、_ユーザー_ フィールドがすべてサポートされています。これらはタスク リストにそれらの種類のカスタム フィールドを作成している場合にのみ適用されます。 |
| **親タスク タイトル** | オプション。親子関係を確立します (上記参照)。 |

> [!NOTE]
>_添付ファイル_、_時間追跡_、_繰り返し_、_作成日_、_完了日_ など、CSV インポートで設定できないフィールドもあります。

## スムーズなインポートのためのヒント

- **CSV を準備する** — 最初の行に明確な列ヘッダーが含まれていることを確認します。Slingshot はこれらを使用してフィールド マッピングを自動検出します。
- **タイトルを入力する** — _タイトル_ 列に空白のセルを含めることはできません。インポート前に空欄を埋めてください。
- **一貫したドロップダウン値を使用する** — 既存のドロップダウン フィールドにインポートする場合は、余分なマッピング手順を避けるために CSV のオプション名を一致させてください。
- **日付形式を確認する** — 標準的な日付形式は自動的に認識されます。
- **複数の値にはカンマを使用する** — _担当者_ や _ユーザー_、_メール_ などの複数値カスタム フィールドの場合、カンマで区切ることで 1 つのセルに複数の値を含めることができます (例: "alice@example.com, bob@example.com")。
- **日付範囲を分割する** — 日付範囲は単一フィールドとしてはサポートされていません。代わりに別々の _開始日_ と _終了日_ 列を使用してください。

## 他のツールからのインポート

すでに別のプロジェクト管理ツールにタスクがありますか? CSV としてエクスポートして Slingshot に取り込むことができます。以下に最も一般的なツールのステップバイステップ ガイドを示します。

### ClickUp からのインポート

ClickUp ではタスクを CSV にエクスポートできます。Slingshot へのインポートのためにエクスポートを準備するには:

1. **ClickUp からエクスポートする** — ClickUp でタスクを CSV にエクスポートします。プロンプトが表示されたら、インポート時に日付が正しく認識されるように日付の **ISO 形式**を選択します。
2. **サブタスクを準備する** — ClickUp は各親タスクのサブタスク ID のリストとしてサブタスクの関係をエクスポートしますが、Slingshot はこれを直接読み取りません。これを Slingshot が理解できる形式に変換するには:
   - エクスポートした CSV を Excel または Google スプレッドシートで開きます。
   - **親タスク タイトル**という新しい列を追加します。
   - 新しい列の最初のデータ行に、次の数式を入力します (すべての行にコピーします):
     ```
     =IFERROR(INDEX($C:$C, MATCH("*"&TRIM(CLEAN(B2))&"*", $F:$F, 0)), "")
     ```
     列の文字をファイルに合わせて調整します:
     - **B** = _タスク ID_ 列
     - **C** = _タスク名_ 列
     - **F** = _サブタスク ID_ 列
   - ファイルを CSV として保存します。
3. **Slingshot にインポートする** — 上記の標準的なインポート手順に従います。マッピング グリッドを確認する際は、**親タスク タイトル**列が**親タスク タイトル** フィールド タイプにマッピングされていることを確認してください。

### Asana からのインポート

Asana のエクスポートには、すぐに使用できるサブタスクの関係が含まれているため、プロセスは簡単です:

1. **Asana からエクスポートする** — Asana でプロジェクトを CSV にエクスポートします。サブタスクは、各サブタスクの親の名前を含む **[親タスク]** 列と共に自動的にエクスポートされます。
2. **Slingshot にインポートする** — 上記の標準的なインポート手順に従います。マッピング グリッドを確認する際は、**[親タスク]** 列を**親タスク タイトル** フィールド タイプにマッピングします。Slingshot は自動的に親子関係を作成します。
