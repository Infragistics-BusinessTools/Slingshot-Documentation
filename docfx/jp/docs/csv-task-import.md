# CSV ファイルからタスクをインポートする

CSV タスク インポートを使用すると、スプレッドシート、他のプロジェクト管理ツール、または CSV にエクスポートできる任意のソースからタスクを Slingshot タスク リストに直接移動できます。Slingshot は列の種類を自動的に検出してタスク フィールドにマッピングするため、セットアップに費やす時間を減らし、作業に集中できます。

> [!NOTE]
> CSV インポートは**ワークスペース オーナー**のみが使用できます。**[インポート]** オプションが表示されない場合は、ワークスペース オーナーに確認してください。

## タスクのインポート方法

### 手順 1: インポートを開始する

CSV インポートを開始するには 2 つの方法があります:

- **タスク リストから** — タスク リストのオーバーフロー メニューをクリックまたはタップし、**[インポート]** を選択します。タスクが追加される「インポート」という新しいセクションが作成されます。
- **セクションから** — 特定のセクションのオーバーフロー メニューをクリックまたはタップし、**[インポート]** を選択します。タスクはそのセクションに直接追加されます。

> [!NOTE]
> タスク リスト メニューから複数回インポートすると、各インポートでインクリメントされた名前 (例: 「インポート」、「インポート 2」、「インポート 3」) の新しいセクションが作成されます。

### 手順 2: ファイルをアップロードする

**[インポート]** を選択すると、ファイル ピッカーが開きます。`.csv` ファイルを選択すると、Slingshot が自動的に解析します。

CSV ファイルは次のガイドラインに従う必要があります:

- **最初の行**には列ヘッダー (フィールド名) が含まれている必要があります。
- 後続の各行はタスクを表します。
- ファイルは最大 **50 列**、**2,000 行**まで対応しています。

### 手順 3: マッピング グリッドを確認する

ファイルがアップロードされると、Slingshot は CSV データを列ごとに整理した**マッピング グリッド**を表示します。各列ヘッダーには以下が表示されます:

- ファイルの **CSV 列名**
- 検出されたフィールドの種類を表す**アイコン**
- フィールドのマッピングを変更するためにクリックまたはタップできる**ドロップダウン**

Slingshot はデータを自動的に分析し、各 CSV 列を最も適合するタスク フィールドにマッピングします。たとえば、日付値を含む「期限」という名前の列は、**期限**フィールドに自動的にマッピングされます。

#### Slingshot が自動検出するもの

| データ パターン | 検出されるフィールドの種類 |
|---|---|
| "true" / "false" 値 | **チェックボックス** |
| 日付値 | **日付** |
| 0 から 5 の数値 | **評価** |
| 0 から 100 の数値 | **手動進捗** |
| その他の数値 | **数値** |
| 長いテキスト (255 文字以上) | **長いテキスト** |
| 繰り返し値を持つ短いテキスト | **ドロップダウン** |
| それ以外 | **テキスト** |

列が既存のフィールドと一致しない場合、Slingshot はそのデータに基づいて新しいカスタム フィールドを作成することを提案します。提案されたフィールドは、インポートを確認したときにのみタスク リストに追加されます — 準備が整うまで何も変更されません。

> [!IMPORTANT]
> **Slingshot ヒント**: 列にデータが含まれていない場合、Slingshot はデフォルトで**テキスト**に設定しますが、列ヘッダーのドロップダウンを使用して任意のサポートされているフィールドの種類に手動で変更できます。

#### 列マッピングの調整

任意の列のマッピングを変更するには、ヘッダーをクリックまたはタップして、ドロップダウンから別のフィールドを選択します。オプションには以下が含まれます:

- **既存のタスク フィールド** — _タイトル_、_ステータス_、_優先度_、_期限_、_担当者_、タスク リストに既存のカスタム フィールドなど。
- **提案される新しいフィールド** — データに基づいて Slingshot が推奨するカスタム フィールド。
- **無視** — インポート中にこの列をスキップします。無視された列はグリッドでグレー表示されます。

#### タスクの種類の選択

マッピング グリッドの上部には**タスクの種類セレクター**があります。ワークスペースで複数のタスクの種類を使用している場合は、それらを切り替えてマッピングに使用可能なフィールドを変更できます。

> [!IMPORTANT]
> タスクの種類を変更すると、すべての列マッピングがリセットされます。CSV データは保存されます — フィールドの割り当てのみがクリアされ、新しいタスクの種類のフィールドに再マッピングできます。

### 手順 4: 不一致を解決する

列が**ドロップダウン**または**ラベル** フィールドにマッピングされ、CSV の値の一部が既存のオプションと一致しない場合、その列ヘッダーに**警告アイコン**が表示されます。

警告アイコンをクリックまたはタップして**値マッピング** ダイアログを開くと、次のことができます:

- 認識されない値を既存のドロップダウンまたはラベル オプションに**マッピング**する
- **新しいオプションを追加** — ダイアログからカラー ピッカーを使用してカスタム カラーで新しいアイテムを直接作成する

ここで作成した新しいオプションは、インポートを確認したときにのみ保存されます。キャンセルすると、既存のフィールドに変更はありません。

### 手順 5: 確認してインポートする

マッピングに満足したら、**[マッピングを適用]** をクリックまたはタップしてインポートを開始します。

> [!NOTE]
> **[マッピングを適用]** ボタンは、少なくとも 1 つの列が**タイトル** フィールドにマッピングされるまで無効です。すべてのタスクにはタイトルが必要で、タイトル列はすべての行に値が必要です — 空白セルのある列はタイトルには使用できません。

未解決のドロップダウンまたはラベルの不一致がある場合、Slingshot は続行する前に値マッピング ダイアログを 1 つずつ案内します。

## インポートの進捗状況の追跡

インポートを確認すると、**進捗ダイアログ**にインポートのステータスがリアルタイムで表示されます。待つ必要はありません — このダイアログを閉じて Slingshot での作業を続けられます。画面の右下隅に小さな**フローティング進捗インジケーター**が表示されます。

インポートが完了すると:

- **すべてのタスクが正常にインポートされた** — 作成されたタスクの合計数のサマリーと、タスク リストに直接移動する**[そこへ移動]** ボタンが表示されます。
- **一部のタスクにエラーがあった** — サマリーには成功したタスク数とインポートできなかった行の詳細が表示されます。

> [!NOTE]
> 一度に実行できるインポートは 1 つだけです。1 つが進行中のときに新しいインポートを開始しようとすると、Slingshot が通知します。

## インポート中のサブタスクの作成

CSV に**親タスク タイトル**列を含めることで、タスク間に親子関係を設定できます。

インポート中にサブタスクを作成するには:

1. CSV の列の 1 つを**親タスク タイトル** フィールドの種類にマッピングします。
2. 各行に、この列に親タスクの**正確なタイトル**を入力します。
3. CSV ファイルで親タスクが子タスクの**上に**表示されていることを確認します。
4. トップレベルのタスクの**親タスク タイトル**列は空白のままにします。

> [!NOTE]
> サポートされるサブタスクのネストは 1 レベルのみです — サブタスクは別のサブタスクの親にはなれません。

**CSV の例:**

| タイトル | ステータス | 親タスク タイトル |
|---|---|---|
| ホームページのデザイン | 進行中 | |
| ワイヤーフレームの作成 | 未着手 | ホームページのデザイン |
| カラー パレットの選択 | 未着手 | ホームページのデザイン |
| API の構築 | 未着手 | |

この例では、「ワイヤーフレームの作成」と「カラー パレットの選択」は「ホームページのデザイン」のサブタスクになり、「API の構築」はトップレベルのタスクのままです。

## サポートされているフィールド

次のタスク フィールドを CSV インポートで設定できます:

| フィールド | 注意事項 |
|---|---|
| **タイトル** | **必須。** すべての行に値が必要です。タイトルにマッピングできる列は 1 つだけです。 |
| **ステータス** | 任意。ステータスにマッピングされた列がない場合、タスクはデフォルトで**未着手**になります。 |
| **説明** | 任意。 |
| **優先度** | 任意。 |
| **期限** | 任意。 |
| **開始日** | 任意。 |
| **担当者** | 任意。1 つのセルでカンマで区切ることで複数の担当者をサポートします。名前またはメール アドレスはワークスペース メンバーと照合されます。 |
| **ラベル** | 任意。 |
| **カスタム フィールド** | _テキスト_、_数値_、_日付_、_チェックボックス_、_評価_、_ドロップダウン_、_長いテキスト_、_手動進捗_、_メール_、_電話番号_、および_人_フィールドがすべてサポートされています。これらはタスク リストでそれらの種類のカスタム フィールドを作成している場合にのみ適用されます。 |
| **親タスク タイトル** | 任意。親子関係を確立します (上記を参照)。 |

> [!NOTE]
> _添付ファイル_、_時間追跡_、_繰り返し_、_作成日_、_完了日_など、一部のフィールドは CSV インポートでは設定できません。

## スムーズなインポートのためのヒント

- **CSV を準備する** — 最初の行に明確な列ヘッダーが含まれていることを確認します。Slingshot はこれらを使用してフィールドのマッピングを自動検出します。
- **タイトルを入力する** — _タイトル_列に空白セルを含めることはできません。インポート前に空白を埋めてください。
- **一貫したドロップダウン値を使用する** — 既存のドロップダウン フィールドにインポートする場合は、追加のマッピング手順を避けるために CSV のオプション名を一致させます。
- **日付形式を確認する** — 標準的な日付形式は自動的に認識されます。
- **複数の値にはカンマを使用する** — _担当者_や_人_、_メール_などの複数値カスタム フィールドには、カンマで区切って 1 つのセルに複数の値を含めることができます (例: "alice@example.com, bob@example.com")。
- **日付範囲を分割する** — 日付範囲は 1 つのフィールドとしてはサポートされていません。代わりに別々の_開始日_と_終了日_の列を使用してください。

## 他のツールからのインポート

すでに他のプロジェクト管理ツールにタスクがありますか? CSV としてエクスポートして Slingshot に取り込むことができます。以下は最も一般的なツールのステップ バイ ステップ ガイドです。

### ClickUp からのインポート

ClickUp ではタスクを CSV にエクスポートできます。Slingshot 用にエクスポートを準備するには:

1. **ClickUp からエクスポート** — ClickUp でタスクを CSV にエクスポートします。プロンプトが表示されたら、インポート中に正しく認識されるように日付の **ISO 形式**を選択します。
2. **サブタスクを準備する** — ClickUp はサブタスクの関係を各親タスクのサブタスク ID のリストとしてエクスポートしますが、Slingshot はこれを直接読み取りません。Slingshot が理解できる形式に変換するには:
   - エクスポートされた CSV を Excel または Google スプレッドシートで開きます。
   - **親タスク タイトル**という名前の新しい列を追加します。
   - 新しい列の最初のデータ行に次の数式を入力します (すべての行にコピーします):
     ```
     =IFERROR(INDEX($C:$C, MATCH("*"&TRIM(CLEAN(B2))&"*", $F:$F, 0)), "")
     ```
     列の文字をファイルに合わせて調整します:
     - **B** = _タスク ID_ 列
     - **C** = _タスク名_ 列
     - **F** = _サブタスク ID_ 列
   - CSV としてファイルを保存します。
3. **Slingshot にインポート** — 上記の標準インポート手順に従います。マッピング グリッドを確認するときに、**親タスク タイトル**列が**親タスク タイトル** フィールドの種類にマッピングされていることを確認します。

### Asana からのインポート

Asana のエクスポートにはすぐにサブタスクの関係が含まれているため、プロセスが簡単です:

1. **Asana からエクスポート** — Asana でプロジェクトを CSV にエクスポートします。サブタスクは各サブタスクの親の名前を含む**親タスク**列と共に自動的にエクスポートされます。
2. **Slingshot にインポート** — 上記の標準インポート手順に従います。マッピング グリッドを確認するときに、**親タスク**列を**親タスク タイトル** フィールドの種類にマッピングします。Slingshot は親子関係を自動的に作成します。
