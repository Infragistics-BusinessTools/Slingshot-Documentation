# Slingshot API

Slingshot API を使用すると、Slingshot のデータにプログラムからアクセスして管理できます。カスタム インテグレーションの構築、ワークフローの自動化、チームで使用する他のツールへの Slingshot の接続が可能です。

## API でできること

Slingshot API を使用すると、次のことができます:

- 外部システムからタスク、プロジェクト、ワークスペースの読み取りと更新。
- ツールの変更に反応して Slingshot に反映するオートメーションの作成。
- レポート用のデータのエクスポート、またはサードパーティ プラットフォームとの同期。
- チームのワークフローに合わせたカスタム アプリとインテグレーションの構築。

## API を使用できるユーザー

Slingshot API は、すべての Slingshot プランのすべてのユーザーが利用できます。API へのアクセスには有効な API トークンが必要で、アカウント設定から生成できます。
