# Slingshot API

Slingshot API を使うと、Slingshot のデータにプログラムでアクセスして管理できます。これにより、カスタム連携の構築、ワークフローの自動化、チームが使う他ツールとの接続が可能になります。

## API でできること

Slingshot API では次のことができます。

- 外部システムからタスク、プロジェクト、ワークスペースを読み取り・更新する
- 目標、目標チェックイン、自動化、カレンダー イベント、会議、トランスクリプトを読み取り・書き込みする
- ツール内の変更に反応し、Slingshot に反映する自動化を作成する
- レポート用にデータを書き出す、またはサードパーティー プラットフォームと同期する
- チームのワークフローに合わせたカスタム アプリや連携を構築する

## API を利用できるユーザー

Slingshot API は、すべての Slingshot プランで利用できます。API へのアクセスには有効な API キーが必要で、**Settings** → **API Keys** から作成できます。
