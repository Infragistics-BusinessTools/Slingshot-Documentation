# Slingshot API

Slingshot API を使用すると、Slingshot のデータにプログラムからアクセスして管理できるため、カスタム統合の構築、ワークフローの自動化、チームが使用する他のツールとの Slingshot の接続が可能になります。

## API で何ができますか?

Slingshot API を使用すると、以下のことができます。

- 外部システムからタスク、プロジェクト、ワークスペースを読み取って更新する。
- ツールの変更に反応して Slingshot に反映させる自動化を作成する。
- レポート用のデータをエクスポートするか、サードパーティのプラットフォームと同期する。
- チームのワークフローに合わせたカスタム アプリと統合を構築する。

## API を使用できるのは誰ですか?

Slingshot API はすべての Slingshot プランのすべてのユーザーが利用できます。API アクセスには有効な API トークンが必要で、アカウント設定から生成できます。
