# Slingshot API

Slingshot API を使用すると、Slingshot データにプログラムでアクセスして管理できるため、カスタム統合を構築したり、ワークフローを自動化したり、Slingshot をチームが使用する他のツールと接続したりできます。

## API でできること

Slingshot API を使用すると、次のことができます:

- 外部システムからタスク、プロジェクト、ワークスペースを読み取り、更新する。
- ツールの変更に反応して Slingshot に反映させる自動化を作成する。
- レポート用にデータをエクスポートしたり、サードパーティ プラットフォームと同期したりする。
- チームのワークフローに合わせたカスタム アプリや統合を構築する。

## API を使用できるユーザー

Slingshot API は、すべての Slingshot プランのすべてのユーザーが利用できます。API アクセスには有効な API トークンが必要で、アカウント設定から生成できます。
