# Slingshot API

Slingshot API を使用すると、Slingshot データにプログラムからアクセスして管理できるため、カスタム インテグレーションの構築、ワークフローの自動化、チームが使用する他のツールとの Slingshot の連携が可能になります。

## API でできること

Slingshot API を使用すると、以下のことができます:

- 外部システムからタスク、プロジェクト、ワークスペースを読み取り、更新する。
- ツールへの変更に反応して Slingshot に反映する自動化を作成する。
- レポート用にデータをエクスポートしたり、サードパーティ プラットフォームと同期する。
- チームのワークフローに合わせたカスタム アプリとインテグレーションを構築する。

## 誰が使えますか？

Slingshot API はすべての Slingshot プランのすべてのユーザーが利用できます。API アクセスには有効な API トークンが必要で、アカウント設定から生成できます。
