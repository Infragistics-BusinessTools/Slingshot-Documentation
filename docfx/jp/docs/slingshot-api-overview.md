# Slingshot API

Slingshot API を使用すると、Slingshot データにプログラムでアクセスして管理できます。カスタム インテグレーションの構築、ワークフローの自動化、チームが使用する他のツールへの Slingshot の接続が可能です。

## API で何ができますか?

Slingshot API を使用すると、以下のことが可能です:

- 外部システムからタスク、プロジェクト、ワークスペースを読み取りおよび更新する。
- ツールの変更に反応し、その変更を Slingshot に反映する自動化を作成する。
- レポート用にデータをエクスポートするか、サードパーティ プラットフォームと同期する。
- チームのワークフローに合わせたカスタム アプリとインテグレーションを構築する。

## 誰が API を使用できますか?

Slingshot API は、すべての Slingshot プランのすべてのユーザーが利用できます。API アクセスには有効な API トークンが必要で、アカウント設定から生成できます。
