# Slingshot API

Slingshot API を使用すると、Slingshot データにプログラムでアクセスして管理できます。カスタム統合の構築、ワークフローの自動化、チームが使用する他のツールへの Slingshot の接続が可能です。

## API でできること

Slingshot API を使用すると、次のことができます:

- 外部システムからタスク、プロジェクト、ワークスペースを読み取り、更新する。
- ツールの変更に反応し、それを Slingshot に反映する自動化を作成する。
- レポート用にデータをエクスポートしたり、サードパーティのプラットフォームと同期する。
- チームのワークフローに合わせたカスタム アプリと統合を構築する。

## API を使用できるのは誰ですか?

Slingshot API は、Slingshot プランのすべてのユーザーが利用できます。API アクセスには有効な API トークンが必要で、アカウント設定から生成できます。
