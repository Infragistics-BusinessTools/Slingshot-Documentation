# 仕事用アカウントに移行

個人のメール アドレスで Slingshot を使い始め、現在は会社で Slingshot アカウントを利用している場合、ワークスペースとタスク リストを仕事用アカウントに送ることができます。リストとタスクはそのまま使える状態で届くため、作り直す必要はありません。

移行はコピーとして実行されます。個人アカウント内の内容は、すべてそのまま残ります。

## 移行されるもの

| 移行されるもの | 移行されないもの |
|---|---|
| タスク リストとそのタスク（元の日付を保持） | ダッシュボード |
| タスク タイプ | 担当者 |
| カスタム フィールド | コメント |
| | 添付ファイル |
| | 自動化 |

## 事前に確認すること

- 送信する各ワークスペースの **Owner** である必要があります。
- 送信元の個人アカウントと、送信先の仕事用アカウントの両方にアクセスできる必要があります。
- 移行できるのは個人アカウント内のワークスペースのみです。すでに会社アカウントに属しているワークスペースは移行できません。

## ワークスペースとタスク リストを送信する

1. 個人アカウントで、ワークスペース名の横にあるオーバーフロー メニューを開き、**Move to my work account** を選択します。
2. 送信したいワークスペースとタスク リストを選択します。開始元のワークスペースはあらかじめ選択されています。
3. **Work email** を入力します。
4. **Send link** をクリック/タップします。

Slingshot は仕事用メール アドレス宛てにリンクを送信します。リンクの有効期限は **7 日間** です。

> [!NOTE]
> コピー対象はリンク送信時点で確定します。送信後に個人アカウント側で行った変更は含まれません。変更を含めるには、移行をキャンセルして再送してください。

## 仕事用アカウントで受け入れる

1. 仕事用メールに届いたメールを開き、リンクをクリック/タップします。
2. 仕事用メールで Slingshot にサインインします。まだアカウントがない場合は、仕事用メールでサインアップします。
3. 送信内容を確認し、**Accept transfer** をクリック/タップします。

ワークスペースは会社アカウントに追加され、タスク リストは **My Tasks** に追加されます。

## 移行ステータスを確認する

個人アカウントでワークスペースの **Settings** を開き、**Transfers** タブに移動します。各移行には次のいずれかのステータスが表示されます。

| ステータス | できること |
|---|---|
| **Waiting for acceptance** | メールが届いていない場合は **Resend link**、または **Cancel transfer**。 |
| **Expired** | **Send again** で新しい移行を開始。 |
| **Accepted** | 対応不要。カードに承認者と承認日時が表示されます。 |

## トラブルシューティング

- **リンクの有効期限が切れた。** リンクは 7 日間有効です。ワークスペースの **Transfers** タブで **Send again** をクリック/タップしてください。
- **"This workspace belongs to a company account and can't be moved." と表示される。** そのワークスペースはすでに会社アカウントに属しているため、移行対象はありません。
- **リンクを開いても動作しない。** リンク送信先の仕事用メールでサインインしていることを確認してください。

それでも解決しない場合は、アプリ内のフィードバック機能からお問い合わせください。詳細は [Feedback](feedback.md) を参照してください。
