# Slingshot API

Slingshot API を使用すると、Slingshot データにプログラムでアクセスして管理できます。これにより、カスタム インテグレーションの構築、ワークフローの自動化、およびチームが使用している他のツールと Slingshot の連携が可能になります。

## API でできること

Slingshot API を使用すると、以下のことが可能です:

- 外部システムからタスク、プロジェクト、ワークスペースの読み取りと更新。
- ツールへの変更に反応し、Slingshot に反映する自動化の作成。
- レポート用にデータをエクスポートしたり、サードパーティ プラットフォームと同期したりする。
- チームのワークフローに合わせたカスタム アプリとインテグレーションの構築。

## API を使用できるユーザー

Slingshot API は、すべての Slingshot プランのすべてのユーザーが利用できます。API アクセスには有効な API トークンが必要です。API トークンはアカウント設定から生成できます。
