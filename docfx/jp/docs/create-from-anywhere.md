# どこからでも作成

Slingshot では、ワークフローを中断せずに新しいコンテンツを作成できます。アプリのどこにいても、数回クリックするだけでタスク、プロジェクト、ワークスペース、ディスカッション、概要、またはダッシュボードを開始できます。

## これは何ですか?

**[作成]** ボタンは、Slingshot ナビゲーション パネルの左上にあります。アプリの任意の画面からあらゆる種類のコンテンツを即座に作成するためのアクセスを提供します。

**[作成]** ボタンを使用すると、新しいアイテムは現在の場所のコンテキストで作成されます。たとえば、ワークスペース内にいる場合、新しいプロジェクトまたはディスカッションはそのワークスペース内に作成されます。

## なぜ重要なのですか?

新しいコンテンツを作成するために画面を切り替えると、集中力が途切れ、作業が遅くなります。**[作成]** ボタンは、Slingshot のどこにいてもすぐに行動できるようにすることで、その摩擦を取り除きます。

- 思い浮かんだときにすぐにタスクを開始する
- 別の場所に移動せずに新しいプロジェクトを立ち上げる
- 正しいワークスペースに自動的にディスカッションやダッシュボードを作成する

## 作成できるもの

**[作成]** ボタンを使用して、次のものを作成できます:

- **タスク** – 現在のプロジェクトまたはワークスペースに新しいタスクを追加します。
- **プロジェクト** – 現在のワークスペース内で新しいプロジェクトを開始します。
- **ワークスペース** – チームまたはイニシアティブ用の新しいワークスペースを作成します。
- **ディスカッション** – 現在の場所に新しいディスカッション スレッドを開きます。
- **概要** – 現在のワークスペースまたはプロジェクトに概要を追加します。
- **ダッシュボード** – 現在のコンテキストで新しい分析ダッシュボードを作成します。

## 使用方法

1. コンテンツを作成したい Slingshot の領域に移動します (たとえば、特定のワークスペースやプロジェクト)。
2. ナビゲーション パネルの左上にある **[作成]** ボタンをクリックします。
3. メニューから作成したいコンテンツの種類を選択します。
4. 名前、説明、設定などの必要な詳細を入力します。
5. **[作成]** をクリックして確認します。

新しいアイテムは自動的に現在の場所に表示されます。

> [!NOTE]
> 新しいアイテムが作成される場所は、**[作成]** をクリックしたときにアプリのどこにいるかによって異なります。ワークスペース内にいる場合、アイテムはそこに作成されます。*[マイ タスク]* などの個人的な領域にいる場合は、移動先を選択するように求められます。

## 例

プロジェクト マネージャーがワークスペース内のタスクを確認していて、今後のイニシアティブに新しいプロジェクトが必要だと気づきます。

1. 左上の **[作成]** をクリックします。
2. **[プロジェクト]** を選択します。
3. プロジェクト名と詳細を入力します。
4. **[作成]** をクリックします。

新しいプロジェクトは現在のワークスペース内にすぐに表示されます。

## ヒントとベスト プラクティス

> [!TIP]
> 時間を節約するために、**[作成]** をクリックする前に正しいワークスペースまたはプロジェクトに移動してください。Slingshot は新しいアイテムをその場所に自動的に配置します。

> [!TIP]
> アイデアが浮かんだときに、アプリでの作業を中断せずに **[作成]** ボタンを使用してタスクやディスカッションをすばやくキャプチャします。
