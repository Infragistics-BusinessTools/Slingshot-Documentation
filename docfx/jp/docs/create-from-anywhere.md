# どこからでも作成

Slingshot では、ワークフローを中断することなく新しいコンテンツを作成できます。アプリのどこにいても、数回クリックするだけでタスク、プロジェクト、ワークスペース、ディスカッション、概要、またはダッシュボードを開始できます。

## これは何ですか?

**[作成]** ボタンは、Slingshot ナビゲーション パネルの左上にあります。アプリのどの画面からでも、あらゆる種類のコンテンツを作成するための即時アクセスを提供します。

**[作成]** ボタンを使用すると、新しいアイテムが現在の場所のコンテキストで作成されます。たとえば、ワークスペース内にいる場合、新しいプロジェクトまたはディスカッションはそのワークスペース内に作成されます。

## 重要な理由

新しいコンテンツを作成するために画面を切り替えると、集中力が途切れ、作業速度が低下します。**[作成]** ボタンは、Slingshot のどこにいても即座に行動できるようにすることで、その摩擦を取り除きます。

- 思いついたときにすぐにタスクを開始
- 離れることなく新しいプロジェクトを開始
- 適切なワークスペースにディスカッションまたはダッシュボードを自動的に作成

## 作成できるもの

**[作成]** ボタンを使用して、以下を作成できます:

- **タスク** – 現在のプロジェクトまたはワークスペースに新しいタスクを追加します。
- **プロジェクト** – 現在のワークスペース内に新しいプロジェクトを開始します。
- **ワークスペース** – チームまたはイニシアチブ用の新しいワークスペースを作成します。
- **ディスカッション** – 現在の場所に新しいディスカッション スレッドを開きます。
- **概要** – 現在のワークスペースまたはプロジェクトに概要を追加します。
- **ダッシュボード** – 現在のコンテキストで新しい分析ダッシュボードを作成します。

## 使用方法

1. コンテンツを作成したい Slingshot の場所 (特定のワークスペースまたはプロジェクトなど) に移動します。
2. ナビゲーション パネルの左上にある **[作成]** ボタンをクリックします。
3. メニューから作成するコンテンツの種類を選択します。
4. 名前、説明、設定など、必要な詳細を入力します。
5. **[作成]** をクリックして確定します。

新しいアイテムが現在の場所に自動的に表示されます。

> [!NOTE]
> 新しいアイテムが作成される場所は、**[作成]** をクリックしたときにアプリ内のどこにいるかによって異なります。ワークスペース内にいる場合、アイテムはそこに作成されます。*[マイ タスク]* などの個人的な場所にいる場合は、移動先を選択するよう求められます。

## 例

プロジェクト マネージャーがワークスペース内のタスクを確認しているときに、今後のイニシアチブに新しいプロジェクトが必要であることに気づきました。

1. 左上の **[作成]** をクリックします。
2. **[プロジェクト]** を選択します。
3. プロジェクト名と詳細を入力します。
4. **[作成]** をクリックします。

新しいプロジェクトが現在のワークスペース内にすぐに表示されます。

## ヒントとベスト プラクティス

> [!TIP]
> **[作成]** をクリックする前に適切なワークスペースまたはプロジェクトに移動すると、時間を節約できます。Slingshot は新しいアイテムをその場所に自動的に配置します。

> [!TIP]
> アプリ内での場所を失わずに、アイデアが浮かんだときにすぐにタスクやディスカッションをキャプチャするために **[作成]** ボタンを使用してください。
